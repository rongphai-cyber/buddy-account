# Buddy Account

โปรแกรมบัญชีสำหรับกิจการไทย ทำงานบนเว็บและติดตั้งในเครื่องได้ — ออกแบบให้ทำได้ **อย่างน้อยทุกอย่างที่โปรแกรม Express ทำได้** ตามคู่มือ Express (248 หน้าจอ) และเพิ่มสิ่งที่ Express ไม่มี

> โปรแกรมแยกจาก WTS-ERP ทั้งโค้ดและฐานข้อมูล

## สถานะรุ่นนี้ (0.1 — แกนหลัก)

| ส่วน | สถานะ |
|---|---|
| ฐานระบบ (P0) | เข้าระบบ ผู้ใช้ เลือกบริษัท/สาขา วันทำการ เมนูหลักตามลำดับ Express แถบเครื่องมือ หน้าต่างค้นหา ปุ่มลัด สร้างบริษัทใหม่ นำข้อมูลจาก Express |
| บัญชีแยกประเภท (P1) | ผังบัญชี (เปลี่ยนเลขที่บัญชีได้) รอบบัญชี/ปิดงวด แผนก สาขา สมุดรายวัน ใบสำคัญ ยอดยกมา งบทดลอง แยกประเภท รายงานสมุดรายวัน งบการเงิน (แบบงบ Express + งบตามผังบัญชี) ตัวสร้างแบบงบ |
| ระบบอื่น | เมนูครบตามโครง Express แต่ยังไม่เปิด — แสดงป้ายเฟส ดู `docs/03_แผนพัฒนา.md` |

ทดสอบกับข้อมูลจริงของบริษัทตัวอย่าง TESTRice ที่ย้ายมาจาก Express: ใบสำคัญ 16,765 ใบดุลทุกใบ, งบทดลองปี 2553 ยอดคงเหลือ **245,718,317.16** ทั้งสองด้าน (ตรงกับ Express), งบแสดงฐานะการเงินตามผังบัญชีดุล

## เริ่มใช้งาน (นักพัฒนา)

ต้องมี Node 22+, pnpm 10, Python 3 (สร้าง schema และย้ายข้อมูล Express)

```bash
pnpm install
pnpm --filter @buddy/web build          # สร้างหน้าจอ
# แบบติดตั้งในเครื่อง (ไม่ต้องลง PostgreSQL — ใช้ PGlite เก็บข้อมูลในโฟลเดอร์)
BUDDY_DATA_DIR=./.data/buddy pnpm dev:server
# หรือแบบ Server/Cloud
DATABASE_URL=postgres://user:pass@localhost/buddy pnpm dev:server
```

เปิด http://localhost:4100 — ครั้งแรกจะให้สร้างผู้ดูแลระบบ · พัฒนาหน้าจอแบบ hot reload: `pnpm dev:web` (http://localhost:5173)

### นำข้อมูลจาก Express

```bash
tools/express-import/import.sh <โฟลเดอร์ข้อมูล Express> postgres://user:pass@localhost/buddy <รหัสบริษัท>
pnpm --filter @buddy/server cli create-admin admin "ผู้ดูแลระบบ" <รหัสผ่าน>
```

### ข้อมูลตัวอย่างสมมุติ (ปี 2568–2569)

```bash
tools/express-import/import.sh <โฟลเดอร์ TESTRice> postgres://…/buddy TESTRice
python3 tools/demo-data/make_demo.py postgres://…/buddy TESTRice DEMO
pnpm --filter @buddy/server cli create-admin admin "ผู้ดูแลระบบ" <รหัสผ่าน>
```

ได้บริษัท DEMO "บริษัท บัดดี้ ดีไซน์ (ตัวอย่าง) จำกัด" ในลูกค้า DEMO — ชื่อและเลขผู้เสียภาษีสมมุติทั้งหมด ยอดเงินเท่าข้อมูลเดิม

### หลายลูกค้า

ผู้ดูแลระบบที่สร้างด้วย `create-admin` คือเจ้าหน้าที่ผู้ให้บริการ — เพิ่มลูกค้าที่เมนู เริ่มระบบ › ลูกค้าผู้ใช้บริการ (ดู `docs/05_หลายลูกค้าและความปลอดภัย.md`)

### ทดสอบ

```bash
pnpm test                       # core + API (PGlite) + ตรวจว่า migration ตรงกับ spec
node apps/web/e2e/smoke.cjs     # ทดสอบหน้าจอด้วย Playwright (ต้องเปิด server ก่อน)
```
