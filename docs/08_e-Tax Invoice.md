# e-Tax Invoice (T7.6)

สร้างแฟ้ม XML ใบกำกับภาษีอิเล็กทรอนิกส์ตาม **ETDA ขมธอ. 3-2560 รุ่น 2.0** (UN/CEFACT Cross Industry Invoice) จากเอกสารขายที่บันทึกแล้ว
— **ยังไม่ลงลายมือชื่ออิเล็กทรอนิกส์ (XAdES)** เพราะกิจการยังไม่มีใบรับรอง (เจ้าของตอบ 29/10/2569) จึงยังยื่นกรมสรรพากรเองไม่ได้

หน้าจอ: การเงิน › ภาษีมูลค่าเพิ่ม › **ส่งออก e-Tax Invoice (XML)** (`/tax/etax`, เมนู `FI.VAT.ETAX` — อ่าน = ดูรายการ, พิมพ์ = ดาวน์โหลด)

ไม่ใช่ใบกำกับภาษี → ไม่อยู่ในรายการตามช่วงวันที่ (เปิดรายฉบับ/เลือกเองได้ข้อความเหตุผล `ETAX_NOT_TAX_INVOICE`): RE/AI/RD ที่ไม่มี VAT ·
**บิลขายเชื่อภาษีเกณฑ์เงินสด (vat_basis 2) ที่มี VAT** — พิมพ์ "ใบแจ้งหนี้" ตั้งแต่ข้อ 87 ใบกำกับภาษีคือ RE ที่รับชำระ (เดิมส่งออกเป็น T02 ด้วย = ใบกำกับภาษีซ้ำ)

เฉพาะเอกสารที่ไม่ยกเลิก · ยังไม่ทำ: ใบรับ (T01), ใบกำกับอย่างย่อ (T05), ใบแจ้งยกเลิก (T07), ลงนาม, นำส่ง

## การแปลงข้อมูล

- ผู้ขาย: ชื่อ/เลขผู้เสียภาษี/ที่อยู่ของกิจการ (เริ่มระบบ › รายละเอียดกิจการ) · สาขาจากสาขาของเอกสาร (ว่าง = 00000)
- ผู้ซื้อ: ชื่อ เลขผู้เสียภาษี สาขา ที่อยู่ **ตามที่บันทึกในเอกสาร** · เลข 13 หลักขึ้นต้น 0 หรือมีสาขา = TXID (13+5 หลัก) · บุคคล = NIDN · อื่น = CCPT · ไม่มี = OTHR N/A
- ที่อยู่: แบบไม่มีโครงสร้าง (LineOne/LineTwo) + รหัสไปรษณีย์ 5 หลักท้ายที่อยู่ + TH (ข้อ 8.7) — ไม่มีรหัสไปรษณีย์ = ยังส่งออกไม่ได้
- ยอดเงินไม่รวม VAT ทุกช่อง (ราคารวม VAT แปลงกลับ) · VAT 7% → ApplicableTradeTax VAT · สินค้ายกเว้น/เอกสารไม่มี VAT → FRE · หักมัดจำ = ส่วนลดท้ายบิล "หักเงินมัดจำ"
- รายการ: ราคาต่อหน่วยไม่รวม VAT · ยอดบรรทัดหลังส่วนลด (`doc_line.net_amount`) · ส่วนต่าง = ส่วนลดบรรทัด (TypeCode 95) · หน่วย = รหัสหน่วยนับ (ว่าง = EA)
- ใบเพิ่ม/ลดหนี้: อ้างใบกำกับเดิม (เลขที่/วันที่/ชนิด) · มูลค่าเดิม (OriginalInformationAmount) / มูลค่าที่ถูกต้อง (LineTotalAmount) / ผลต่าง (DifferenceInformationAmount) ไม่รวม VAT
  · เหตุผล: ลดหนี้ที่รับคืนสินค้า = CDNG05 · อื่น ๆ = CDNG99/CDNS99/DBNG99/DBNS99 พร้อมเหตุผลจากหมายเหตุเอกสาร (ต้องมี)
- **ใบเสร็จรับเงิน/ใบกำกับภาษี (RE → T03, `etaxReceiptParts`):** ยอดจาก `receiptVatSummary` (core posting.ts) ตัวเดียวกับใบพิมพ์ RE และ `settlementVatParts` ของรายงานภาษีขาย
  → ฐาน VAT = มูลค่าที่มี VAT · VAT = ภาษีถึงกำหนด · FRE = มูลค่าที่ไม่มี VAT (ยกเว้น 0% บิลไม่มี VAT เช่นค่าปรับ) · ยอดรวม = รวมยอดชำระ (ตรงใบพิมพ์ถึงสตางค์)
  · รายการ = รายการของบิลที่ชำระ ยอดไม่รวม VAT (ยอดชำระ − VAT ของบิล แบ่งตามยอดบรรทัด) · ชำระบางส่วน = จำนวน 1 × ยอดที่ชำระ "(ชำระบางส่วนของ …)" · ใบลดหนี้ที่หัก/บิลไม่มีรายการ = 1 บรรทัดต่อบิล
  · ตัดบิลหลายอัตรา VAT = ส่งออกไม่ได้ (แยกใบเสร็จ) · วันที่ = วันที่ใบเสร็จ
- **รับเงินมัดจำ (AI → T03):** แปลงแบบเดียวกับบิลขาย · รายการ = คำอธิบายมัดจำ (ว่าง = "รับเงินมัดจำ")
- **คืนเงินมัดจำที่มี VAT (RD → 81, `etaxDepositRefundParts`):** อ้างใบกำกับเดิม = **ใบรับเงินมัดจำทุกใบที่คืน** (เลขที่ วันที่ ชนิด T03) — `AdditionalReferencedDocument` ใน XSD เป็น 0..ไม่จำกัด จึงใส่ครบทุกใบ (1 ใบ = รูปแบบเดิมของ CN/DR)
  · มูลค่าเดิม / ที่ถูกต้อง / ผลต่าง จาก `depositCreditNoteAmounts` ตัวเดียวกับใบพิมพ์ RD (ที่ถูกต้อง = เดิม − ลดหนี้ครั้งก่อน − ผลต่าง) · VAT ของผลต่าง = VAT ของ RD (กฎปิดยอดตรงสตางค์ ข้อ 85)
  · เหตุผล = **รหัสที่ผู้ใช้เลือกในใบคืนเงินมัดจำ** (`doc_header.etax_purpose_code` · รายการ ETDA CDNG01-05/99 CDNS01-04/99 · HANDOFF ข้อ 90 · docs/19 ข้อ 8) — ค่าเริ่มต้น/ใบเดิม **CDNS04 บอกเลิกสัญญาบริการ** (คืนมัดจำเมื่อเลิกสัญญา — docs/19 ข้อ 6) · มัดจำค่าสินค้าแนะนำ CDNG99 · รหัส 99 ต้องมีเหตุผล + ข้อความ = หมายเหตุของ RD · รายการ = 1 บรรทัดต่อใบมัดจำ มูลค่าก่อน VAT ที่คืน
- ตรวจก่อนส่งออก (`validateEtax` ใน `packages/core/src/etax.ts`) ข้อความบอกวิธีแก้ · ฐาน + VAT = ยอดรวม · ยอดรายการ − มัดจำ = ฐานภาษี

## ยังต้องทำเมื่อพร้อม

1. ลงนาม XAdES-BES ด้วยใบรับรองของกิจการ (ต้องมีใบรับรองจาก CA ที่กรมสรรพากรยอมรับ) — เพิ่มที่เดียวต่อจาก `buildEtaxXml`
2. ตรวจกับชุดตรวจของกรมสรรพากร/ETDA (XSD + Schematron) ก่อนใช้งานจริง — ยังไม่ได้ทดสอบกับโปรแกรมตรวจของทางราชการ
3. นำส่ง (e-Tax Invoice by Email / Service Provider / Host-to-Host) ตามช่องทางที่เลือก
