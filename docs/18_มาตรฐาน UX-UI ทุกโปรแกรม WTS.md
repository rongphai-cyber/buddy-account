# มาตรฐาน UX/UI — ใช้กับทุกโปรแกรม WTS Solutions

**ผู้ช่วยทุกเซสชันต้องอ่านไฟล์นี้ก่อนทำหรือแก้หน้าจอใด ๆ** (Buddy Account · WTS-POS · WTS-Living · โปรแกรมที่ทำต่อ)
เจ้าของไม่ต้องสั่งซ้ำ — ถ้างานไหนทำไม่ได้ตามข้อใด ต้องแจ้งเจ้าของพร้อมเหตุผล

รายละเอียดเต็มและสถานะราย Buddy/WTS-POS: `docs/13_ข้อกำหนดหลักของเจ้าของ.md` · หน้าตา/สี/ส่วนประกอบ: `docs/wts-design-system/`

## หลักใหญ่ 5 ข้อ

1. **ใช้ง่ายแบบมืออาชีพ** — มือใหม่ใช้ได้โดยไม่ต้องอ่านคู่มือ คนคีย์เร็วใช้คีย์บอร์ดล้วนได้จนจบงาน
2. **ต้นแบบคือหน้าจอขายเงินเชื่อ (IV) ของ Express** — ทำได้อย่างน้อยเท่า Express แล้วใช้มาตรฐานเดียวกับทุกระบบ (ซื้อ ขาย สมุดรายวัน การเงิน สต๊อก POS ฯลฯ)
3. **หน้าตาเหมือนกันทุกหน้า ทุกโปรแกรม** — ปุ่มเดียวกันอยู่ที่เดิม ชื่อเดิม ปุ่มลัดเดิม
4. **กันผิดตั้งแต่ตอนคีย์** — เตือนทันทีที่ช่อง ไม่ปล่อยให้ไปเจอข้อผิดพลาดตอนกดบันทึก
5. **ข้อมูลถูกต้องตามหลักบัญชีและภาษี** — หน้าจอสวยต้องไม่แลกกับความถูกต้อง

## 1. ปุ่มและแถบเครื่องมือ

- [ ] แถบเครื่องมือครบทุกหน้าเอกสาร: **+ ใหม่ (Alt+A/Insert) · แก้ไข (Alt+E) · บันทึก (F9/Ctrl+S) · ยกเลิกเอกสาร (Alt+C) · ลบ (Alt+D) · พิมพ์ (Alt+P) · หมายเหตุ (Alt+R) · รายละเอียด/ประวัติ (Ctrl+I) · ⏮ ◀ ▶ ⏭ · ปิดหน้าจอ (Alt+X) · กลับ (Esc)**
- [ ] ปุ่มหลัก (บันทึก) **หน้าละ 1 ปุ่ม** เด่นที่สุด อยู่ตำแหน่งแรก · ปุ่มอันตราย (ลบ/ยกเลิก) สีแดง อยู่ขวาสุด
- [ ] ปุ่มมี **ป้ายข้อความ + ปุ่มลัด** (เช่น "บันทึก F9") · ชี้เมาส์ขึ้นคำอธิบาย · มีแถบปุ่มลัดท้ายหน้า
- [ ] กดแล้ว **ปุ่มหมุนแสดงว่ากำลังทำงาน และกดซ้ำไม่ได้** (กันบันทึกซ้ำ)
- [ ] ปุ่มบนจอสัมผัสสูง ≥ 44 px · ปุ่มจอแคชเชียร์ ≥ 56 px
- [ ] ⏮◀▶⏭ ไปเอกสารชนิดเดียวกันเรียงตามเลขที่ · มีงานแก้ค้างต้องถามก่อนไป

## 2. การคีย์ข้อมูล — Enter พาไปจนจบการบันทึก

- [ ] **Enter = ช่องถัดไป** ตามลำดับที่ใช้งานจริง (ข้ามช่องที่ไม่ต้องคีย์) · **Shift+Enter = ย้อน** · ช่องหลายบรรทัด Enter ขึ้นบรรทัดใหม่
- [ ] เพิ่มใบใหม่ → **เคอร์เซอร์อยู่ช่องแรกทันที** (เช่น รหัสลูกค้า) · กดแก้ไข → ไปช่องแรกที่แก้ได้
- [ ] **ลำดับการคีย์เอกสาร: ส่วนหัว → ส่วนท้าย (หักมัดจำ ส่วนลดท้ายบิล VAT % หมายเหตุ) → รายการ** (เจ้าของ 18/11/2569) — Enter ช่องสุดท้ายของหัวไปส่วนท้าย · Enter ที่หมายเหตุไปรายการแรก (ช่องรหัสว่าง = เปิดรายการให้เลือกเลย) · Shift+Enter ในหมายเหตุ = ขึ้นบรรทัดใหม่
- [ ] ตารางรายการ: Enter ไปทีละช่อง · แถวสุดท้าย = เพิ่มบรรทัดใหม่ · **Enter ที่ช่องรหัสว่าง = เปิดรายการสินค้าให้เลือก** (คีย์ต่อได้เลย ไม่ถาม) · **Esc ที่ช่องรหัสว่าง/ปิดรายการโดยไม่เลือก = ไม่คีย์ต่อ → ถาม บันทึก (F9 ค่าเริ่มต้น) · กลับไปคีย์ต่อ · ไปส่วนหัว · ยกเลิกเอกสาร (ใบใหม่)** — ไม่ข้ามออกจากตารางเงียบ ๆ
- [ ] **ใบใหม่มีประเภทเอกสารเสมอ** เลขที่ถัดไปขึ้นทันที (ประเภทที่ผู้ใช้เลือกล่าสุดในหน้าจอนั้น หรือประเภทหลัก เช่น IV ก่อน IVL) · เปลี่ยนจากแถบประเภทได้
- [ ] **ช่องสุดท้าย Enter → หน้าต่าง "คีย์ครบแล้ว — บันทึก?"** (Enter = บันทึก · บันทึก + ใบใหม่ · กลับไปแก้) · เอกสารที่มีตารางรายการ: คำถามบันทึกขึ้นเมื่อกด Esc ที่ช่องรหัสว่าง (ดูข้อบน)
- [ ] **ช่องบังคับ (ป้าย \*) ว่าง กด Enter ไม่ผ่าน** — อยู่ช่องเดิม กรอบแดง เตือนติดช่อง · ถ้าเป็นช่องรหัส ให้เปิดรายการให้เลือกเลย
- [ ] เอกสารที่มีการรับ/จ่ายเงิน: ก่อนบันทึก **ถามวิธีรับ/จ่ายเงิน** (เงินสดทั้งจำนวน = Enter / วิธีที่ตั้งไว้ / แยกหลายวิธี) · ยอดไม่ครบต้องถาม
- [ ] ช่องที่กำลังคีย์มี **กรอบสีชัด** · ช่องกรอกทุกช่องมีเส้นขอบชัด
- [ ] ปิดหน้าต่าง/ออกจากหน้าที่ยังไม่บันทึก → **ถามยืนยันก่อน**

## 3. ช่องค้นหาและช่องเลือก

- [ ] **กล่องเดียว** พิมพ์ค้นและเลือกในกล่องเดียวกัน + ปุ่ม 🔍 ในกล่อง + **F4** เปิดรายการ
- [ ] ค้นได้ทั้ง รหัส ชื่อ เลขที่ เลขผู้เสียภาษี เบอร์โทร · ไม่สนเว้นวรรค/ตัวพิมพ์/ขีด · หลายคำไม่สนลำดับ
- [ ] ผลค้นหาแสดงข้อมูลรอง (เลขผู้เสียภาษี เบอร์โทร ยอดค้าง รูปสินค้า) ให้ตรวจก่อนเลือก · ลูกศร + Enter เลือกได้
- [ ] **ค้นไม่พบ → กด Insert เพิ่มรายการใหม่ได้จากหน้าต่างนั้นเลย** (เปิดแล้วอยู่ช่องรหัส) · ค่าที่เลือกไว้เดิมห้ามหาย
- [ ] ช่องที่ต้องมีเงื่อนไข แสดง **เฉพาะรายการที่ใช้ได้** (เช่น รับชำระหนี้ แสดงเฉพาะลูกค้าที่มีบิลค้าง พร้อมจำนวนบิล/ยอด) · เลือกแล้วใช้ไม่ได้ → เตือนทันที ล้างช่องให้เลือกใหม่
- [ ] **ค่าเริ่มต้น** เติมให้เห็นทันที: คลังหลัก · สำนักงานใหญ่ · วันนี้ (เวลาไทย) · ค่าจากครั้งก่อนของคู่ค้าเดิม

## 4. วันที่ ตัวเลข เงิน

- [ ] วันที่แสดง/รับ **วว/ดด/ปปปป พ.ศ.** ทุกเครื่อง (ตามระบบปีของบริษัท) · มีตัวอย่างรูปแบบ + ปุ่ม 📅 ปฏิทิน (F4/Alt+↓) · พิมพ์ได้หลายแบบ (12/10/2569 · 12102569 · 12/10/69 · ค.ศ.) · วันที่ไม่มีจริงไม่รับ
- [ ] "วันนี้" = **เวลาไทย** ห้ามใช้เวลาสากล
- [ ] เงิน **ชิดขวา คั่นหลักพัน ทศนิยม 2 ตำแหน่ง** ตัวเลขความกว้างคงที่ (฿1,250.00) · ขณะคีย์แสดงค่าดิบ เลือกทั้งช่องให้พิมพ์ทับ
- [ ] ส่วนลด: `200` = บาท · `5%` / `5+` = เปอร์เซ็นต์ · `5+2+` ซ้อน · `5+,200` = 5% แล้วลดอีก 200 · รูปแบบผิดเตือนทันที · คีย์จำนวนเงินเอง → คิดส่วนลด/ราคาให้

## 5. ข้อความแจ้ง

- [ ] ข้อความทั่วไป **กลางจอ ตัวใหญ่ สีตามชนิด** (✓ เขียว · ⚠ ส้ม · ✕ แดง) · ข้อความเกี่ยวกับช่อง **ติดที่ช่องนั้น**
- [ ] ข้อผิดพลาดบอก **เกิดอะไร + ต้องทำอะไรต่อ** (เช่น บอกเลขที่เอกสารที่ต้องยกเลิกก่อน) · ใช้ Message# ของ Express ถ้ามี
- [ ] สถานะมีคำกำกับเสมอ **ไม่ใช้สีอย่างเดียว**
- [ ] บอกตามจริง: เอกสารที่ไม่ลงบัญชีแจ้ง "(ไม่ลงบัญชี)" ไม่ใช่ "ลงบัญชีแล้ว"

## 6. หน้าจอเอกสาร

- [ ] เปิดเอกสารเดิม = **ดูอย่างเดียว** (ช่องพื้นเทา ป้ายบอก) → ต้องกด **แก้ไข** ก่อน · บันทึกแล้วกลับเป็นดูอย่างเดียว · "เลิกแก้ไข" ทิ้งการแก้
- [ ] **ยกเลิก ≠ ลบ**: ยกเลิก = ยังเห็น ป้ายแดง "เอกสารยกเลิก — เหตุผล" ตัวเลขขีดฆ่า ไม่ลงบัญชี · ลบ = เฉพาะที่ยกเลิกแล้ว ต้องมีสิทธิ์ + เหตุผล เลขที่ว่างให้ใช้ใหม่ · **เอกสารที่มีเอกสารอื่นอ้างถึง ยกเลิก/ลบไม่ได้** บอกว่าต้องจัดการใบไหนก่อน · ทุกการกระทำเก็บประวัติ
- [ ] ช่อง **เลขที่เอกสาร** แสดงตัวนำหน้า + ตัวอย่างเลขถัดไป · คีย์เองได้แต่ลบตัวนำหน้าไม่ได้ ห้ามซ้ำ · ไม่คีย์ = เลขอัตโนมัติ
- [ ] **มุมขวาบนบอกสาขา** ที่บันทึก (🏢) ทุกเอกสาร · รายงานแยก/รวมสาขาได้ หัวรายงานบอกสาขา
- [ ] แท็บ **"ตัวอย่างการลงบัญชี"** ตั้งแต่ใบใหม่ (Dr/Cr ตรงกับตอนบันทึกจริง) · บันทึกแล้ว = "ใบสำคัญที่ลงบัญชี" คลิกไปได้
- [ ] **แท็บข้อมูลที่เกี่ยวข้องคลิกดูได้เสมอ** แม้ยังไม่กดแก้ไข: ภาษีซื้อ/ขาย · ภาษีหัก ณ ที่จ่าย (พิมพ์ 50 ทวิ) · รับ/จ่ายชำระ · เช็ค · มัดจำ
- [ ] **เลขที่อ้างอิงทุกจุดเป็นลิงก์** เปิดเอกสารนั้นได้ · ถ้ากำลังคีย์ค้างให้เปิดแท็บใหม่ไม่ทิ้งงาน · Back กลับหน้าเดิม
- [ ] หมายเหตุ 2 แบบ: **เอกสาร** (Alt+R) และ **รายการ** (Alt+M ต่อบรรทัด หลายบรรทัด ติ๊กพิมพ์)
- [ ] เตือนเชิงธุรกิจตอนเลือกคู่ค้า: มีเงินมัดจำ → ถามจะหักไหม · เกินวงเงิน · ระงับการขาย/จ่าย (ป้ายแดง)
- [ ] ข้อมูลยาว **แบ่งแท็บย่อย** · ขนาดช่องและการจัดเรียงดูง่าย จัดกลุ่มตามลำดับการคีย์
- [ ] **ข้อมูลที่มีหมวดหมู่ → แท็บย่อยตามหมวด** (เจ้าของ 05/11/2569) ไม่ให้หน้าจอยาวลงไปเรื่อย ๆ — ทั้งหน้าฟอร์ม (เช่น ข้อมูลทั่วไป · ที่อยู่/ติดต่อ · บัญชี/ภาษี · เครดิต · อื่น ๆ) และหน้ารายการ/ตั้งค่าที่มีหลายกลุ่ม (เช่น สินค้าแยกตามหมวด เมนูแยกตามหมวด ตั้งค่าแยกตามเรื่อง) · แท็บมีจำนวนรายการกำกับ · แท็บที่มีช่องบังคับว่าง/ผิดมีจุดแดง และกดบันทึกพาไปแท็บนั้น · จำแท็บล่าสุด · มือถือแท็บเลื่อนข้างในแถบเดียว
- [ ] **ปุ่มแท็บ/ตัวเลือกอยู่ที่เดิมเสมอ** (เจ้าของ 14/11/2569) — กดแท็บไหนก็แสดงเนื้อหาแท็บนั้น ปุ่มไม่ย้ายไปหน้าสุด ลำดับแท็บคงที่ · กฎ "ปุ่มหลักมาก่อน" ใช้กับแถวปุ่มทำงานเท่านั้น ไม่ใช้กับแถบแท็บ (`role="tablist"` / `aria-selected` / `aria-pressed`)
- [ ] **ซื้อ+เจ้าหนี้ กับ ขาย+ลูกหนี้ หน้าตาและการทำงานเหมือนกัน** ต่างเฉพาะที่หลักบัญชี/ภาษีบังคับ
- [ ] **เอกสารทั้งใบพอดีจอเดียวแบบ Express: ส่วนหัว / ส่วนกลาง / ส่วนท้าย** (เจ้าของ 18/11/2569 รอบ 3 · ต้นแบบหน้าขายเงินเชื่อ Express) · ใช้กับทุกเอกสาร: ซื้อ ขาย ค่าใช้จ่าย รับ/จ่าย มัดจำ วางบิล **คลังสินค้า ยอดยกมาสินค้า เงินสดย่อย ธนาคาร ใบนำฝากเช็ค** — คอมพิวเตอร์/โน้ตบุ๊ก/iPad แนวนอน (กว้าง ≥1024 สูง ≥600):
  - **ส่วนหัว** 2 กล่องคู่กัน: ซ้าย = คู่ค้า (รหัส · Bill to/สาขา · ที่อยู่ · สถานที่ส่งของ · อ้างอิง) · ขวา = ข้อมูลเอกสาร (เลขที่ วันที่ เครดิต แผนก พนักงาน ฯลฯ) · **ป้ายชื่ออยู่ซ้ายช่อง** ช่องเตี้ย ชิดกัน · สูงไม่เกินราว 200px ที่จอ 1280
  - **ส่วนกลาง** ตารางรายการสูงเต็มที่เหลือ เลื่อนในตัวเอง หัวคอลัมน์และแถว "+ เพิ่มบรรทัด" ติดอยู่ · แถวบางราว 31px
  - **ส่วนท้าย** หมายเหตุซ้าย + ยอดรวมเต็ม (จำนวนเงิน ส่วนลด VAT รวมทั้งสิ้น) ขวา **อยู่ในจอเสมอ** ไม่ต้องเลื่อนหน้า · ท้ายสุดคือแถบปุ่มลัด
  - จอกว้าง 901–1365px เปิดหน้าเอกสาร = ย่อเมนูข้างให้อัตโนมัติ (กด » ขยายเองได้ แล้วไม่ย่อให้อีก) · มือถือ/จอตั้งเรียงลงตามปกติ
- [ ] **หน้าเอกสารกะทัดรัด เห็นรายการและยอดรวมในจอเดียว** (เจ้าของ 18/11/2569 รอบ 1–3 · ทุกเอกสารซื้อ ขาย รายจ่าย รับ/จ่าย):
  - **ส่วนบนติดใต้หัวโปรแกรมทั้งก้อน** ตอนเลื่อนจอ: ชื่อ/เลขที่เอกสาร + สาขาที่บันทึก (🏢) + สถานะ · แถบเครื่องมือ · แถบประเภทเอกสาร — บางที่สุด พื้นทึบ ไม่บังช่อง · คอมพิวเตอร์แถบเครื่องมือ **แถวเดียว** · มือถือไม่ติดค้างบนจอ
  - **หัวเอกสารเตี้ย** ระยะห่างแคบ · คำอธิบายใต้ช่องที่เป็นข้อความยาวย้ายเป็น **ⓘ ชี้เมาส์ดู** (มือถือยังแสดงใต้ช่อง) · จอกว้างหลายคอลัมน์ · **รหัสคู่ค้ากับ Bill to/สาขา อยู่แถวเดียวกัน** ที่อยู่ใต้ทั้งสองช่อง · ช่องอื่น (อ้างอิง สถานที่ส่ง ฯลฯ) อยู่คอลัมน์ขวา
  - **ตารางรายการแสดงบรรทัดว่างราว 5 บรรทัด** (จอเตี้ยน้อยกว่านั้น 2–4) ให้ส่วนท้ายอยู่จอเดียวกัน · Ctrl+Ins / "+ เพิ่มบรรทัด" เพิ่มต่อได้ · บรรทัดว่างไม่บันทึก ไม่นับ · Enter ไล่ลงตามบรรทัด
  - **ยอดรวมเห็นตลอดขณะคีย์**: จอที่ส่วนท้ายอยู่ในจอแล้ว ใช้ตารางยอดรวมเต็ม · จอเตี้ย (สูง < 600) แสดง **แถบสรุปยอด** ติดเหนือแถบปุ่มลัด · ข้อความ "เลือกประเภทเอกสารก่อน" เป็นป้ายเล็กข้างแถบประเภท ไม่กินแถว
  - **มีรหัสลูกค้า/ผู้จำหน่าย → แสดงที่อยู่ เลขผู้เสียภาษี สาขา ใต้ช่องรหัส** 1–2 บรรทัด ยาวเกินตัดท้าย ชี้เมาส์ดูเต็ม · เอกสารที่บันทึกแล้วแสดงที่อยู่ตามที่ออกในเอกสาร
- [ ] **เอกสารซื้อ/ขายที่คีย์ ช่องที่ต้องมีของแต่ละรายการบังคับด้วยการทำงาน ไม่ใช้ \* ที่หัวคอลัมน์** (เจ้าของ 18/11/2569 รอบ 1–2): **คลัง** (สินค้าที่มีสต๊อก — บริการไม่ต้อง) · **จำนวน** · **หน่วยนับ** — เลือกสินค้าแล้วเติมคลัง/หน่วยให้ · ช่องว่างกรอบแดงทันที · กด Enter ที่ช่องว่างไม่ผ่าน เตือนติดช่อง · บันทึกไม่ได้ บอกบรรทัดและวิธีแก้ แล้วพาไปช่องนั้น · ตรวจซ้ำที่ server (เฉพาะคีย์จากหน้าจอ — เอกสารจากโปรแกรมอื่น/นำเข้าใช้ค่าเริ่มต้น) · เอกสารเดิมยังเปิดดู/ยกเลิกได้ ตรวจเมื่อแก้แล้วบันทึก
- [ ] **เอกสารที่ลงบัญชีทุกหน้าจอ มีทั้ง 📷 อ่านบิลด้วย AI และ ⬆ นำเข้า Excel** (เจ้าของ 21/11/2569 "ทุกเอกสารที่จะคีย์ ขอมีอ่านบิลด้วย Ai และ นำเข้า Excel ทั้งสองแบบ … แล้วแต่ลูกค้าจะเลือกวิธีไหนเอง" · 22/11/2569 "เอกสารที่ไม่มีผูกที่ต้องลงบัญชี ไม่ต้องมีนำเข้า excel หรือ Ai ได้ (ยกเว้นข้อมูลหลัก เช่น ลูกหนี้ เจ้าหนี้ สินค้า ทะเบียนทรัพย์สิน)") — ที่เดียวกันบนแถบเครื่องมือ (ต้นแบบ ซื้อเงินเชื่อ): 📷 อ่านบิลด้วย AI ก่อนปุ่ม รายการ · ⬆ นำเข้า Excel ต่อท้าย
  - **มีทั้งสองปุ่ม**: ขายเชื่อ/ขายสด/เพิ่มหนี้/ลดหนี้ (IV HS DR CN) · ซื้อเชื่อ/ซื้อสด/เพิ่มหนี้/ลดหนี้ (RR HP CP DN) · มัดจำรับ/จ่าย รายได้อื่น ค่าใช้จ่ายอื่น (AI AE OI OE) · รับชำระหนี้/จ่ายชำระหนี้ (RE PS) · ใบสำคัญ (JV — นำเข้า Excel หลายสมุดรายวัน) · ฝาก ถอน โอน รายได้/ค่าใช้จ่ายธนาคาร (BD BW BT BU BV) · เบิกใช้ โอนย้ายคลัง ปรับปรุงสินค้า ปรับต้นทุน (OU RL JU CA) · จ่ายเงินสดย่อย (DP)
  - **ไม่มีปุ่ม (เอกสารไม่ลงบัญชี หรือไม่มีกระดาษ/แฟ้มให้อ่าน)**: ใบเสนอราคา ใบสั่งขาย ใบสั่งซื้อ (ไม่ลงบัญชี — เจ้าของ 22/11/2569 "เอาออก" ทั้งปุ่มและที่ server) · ใบวางบิล/ใบรับวางบิล (ไม่ลงบัญชี — รวมบิลที่มีในระบบแล้ว) · ใบนำฝากเช็ค (เลือกเช็คในทะเบียน) · ลูกหนี้/เจ้าหนี้คงค้างยกมา มัดจำยกมา (ตั้งระบบครั้งเดียว) · คืนเงินมัดจำ (คืนจากมัดจำที่มีในระบบ) · เบิกชดเชยเงินสดย่อย VR (ชดเชยจากใบจ่ายเงินสดย่อยที่มีแล้ว)
  - **ข้อมูลหลักมีนำเข้า Excel**: ลูกค้า (ลูกหนี้) ผู้จำหน่าย (เจ้าหนี้) สินค้า ทะเบียนทรัพย์สิน · AI ไม่บังคับ — เสนอเฉพาะเมื่อมีกระดาษให้อ่านชัด (เช่น หนังสือรับรอง/ภ.พ.20 → ผู้จำหน่าย)
  - **อ่านบิลด้วย AI** เติมเป็น**ร่าง** ให้ตรวจก่อนบันทึก (ไม่บันทึกเอง) · รุ่น Claude/เพดานค่าใช้จ่ายเดือนของบริษัท · ส่งเฉพาะข้อความได้ (อ่านภาพในเครื่องก่อน) · ซ่อนเมื่อบริษัทยังไม่ตั้งกุญแจ API · **ฝั่งซื้อ** = บิลของผู้จำหน่าย (ผู้จำหน่าย = ผู้ขายในบิล) · **ฝั่งขาย** = ใบสั่งซื้อของลูกค้า บิลเขียนมือ (ลูกค้า = ผู้ซื้อในเอกสาร) · **ไม่มีคู่ค้า** (สลิปธนาคาร ใบเบิก/โอนสินค้า ใบเสร็จเงินสดย่อย บิลลงใบสำคัญ) = ไม่หาคู่ค้า · เอกสารที่บรรทัดเป็นคำอธิบาย+เงิน (มัดจำ) ไม่เลือกรหัส
  - **นำเข้า Excel** = แบบฟอร์มตามหน้าจอนั้น (ช่องต้องมีหัวมี \* · แผ่นคำอธิบาย) · ตรวจแฟ้มก่อน (ไม่บันทึก) · บันทึกทั้งแฟ้มหรือไม่บันทึกเลย · บันทึกด้วยการบันทึกเดียวกับหน้าจอ + ประวัติการใช้งาน · ใช้บริษัทจาก session · แผ่นรับ/จ่ายชำระใส่เฉพาะวิธีที่ไม่ใช่เงินสด ส่วนที่เหลือ = เงินสด รวมเกินยอด = ผิด (HANDOFF 172)
  - หน้าจอใหม่ที่ลงบัญชีต้องมีทั้งสองปุ่ม · ถ้าไม่ควรมี ให้เขียนเหตุผลในรายการ "ไม่มีปุ่ม" ข้างบน และถามเจ้าของก่อนตัดสินว่า "บิล" ของหน้าจอนั้นคืออะไร
- [ ] **Bill to = สาขาของลูกค้ารายเดียวกัน** (เจ้าของ 18/11/2569) ไม่ใช่รหัสลูกค้าอื่น — เลือกจากสำนักงานใหญ่/สาขาตามแฟ้มลูกค้า + แท็บสาขาในรายละเอียดลูกค้า · สถานที่ส่งของเลือกจากของสาขานั้น · ลูกหนี้ยังเป็นรหัสลูกค้า · ใบกำกับ/รายงานภาษีขายใช้ชื่อลูกค้า + ที่อยู่และเลขที่สาขา

4. ทดสอบอัตโนมัติ + typecheck ผ่าน (ดู exit code) · งานที่กระทบยอดเงินคิดตัวเลขเทียบด้วยมือ
5. รายงานเจ้าของเป็นภาษาไทย: ทำอะไร · ลองอะไรแล้วได้ผลอะไร · อะไรยังไม่ได้ทำ/ยังไม่ได้ลอง · จบด้วยข้อความที่เจ้าของพิมพ์ต่อได้เลย

## วิธีทำงานกับเจ้าของ

- เจ้าของไม่ได้เขียนโปรแกรม — ผู้ช่วยทำงานเทคนิคเองทั้งหมด ถามเฉพาะเรื่องที่เจ้าของต้องตัดสินใจ/ทำเอง (พร้อมขั้นตอนทีละคลิก)
- ตัวเลือกให้เป็นปุ่มกด แนะนำอันแรก · เจ้าของส่งภาพหน้าจอวงแดงมา = แก้ตามจุดที่วง แล้วลองในเบราว์เซอร์ก่อนรายงาน
- เจ้าของสั่งเพิ่มเรื่องใหม่ที่ใช้กับทุกหน้าจอ → **เพิ่มลงไฟล์นี้** (และสถานะใน `docs/13`) ทันที เพื่อไม่ต้องสั่งซ้ำ
