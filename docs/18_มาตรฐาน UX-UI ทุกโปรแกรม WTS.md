# มาตรฐาน UX/UI — ใช้กับทุกโปรแกรม WTS Solutions

**ผู้ช่วยทุกเซสชันต้องอ่านไฟล์นี้ก่อนทำหรือแก้หน้าจอใด ๆ** (Buddy Account · WTS-POS · WTS-Living · โปรแกรมที่ทำต่อ)
เจ้าของไม่ต้องสั่งซ้ำ — ถ้างานไหนทำไม่ได้ตามข้อใด ต้องแจ้งเจ้าของพร้อมเหตุผล

รายละเอียดเต็มและสถานะราย Buddy/WTS-POS: `docs/13_ข้อกำหนดหลักของเจ้าของ.md` · หน้าตา/สี/ส่วนประกอบ: `docs/wts-design-system/`

## หลักใหญ่ 5 ข้อ

1. **ใช้ง่ายแบบมืออาชีพ** — มือใหม่ใช้ได้โดยไม่ต้องอ่านคู่มือ คนคีย์เร็วใช้คีย์บอร์ดล้วนได้จนจบงาน
2. **ต้นแบบคือหน้าจอขายเงินเชื่อ (IV) ของ Express** — ทำได้อย่างน้อยเท่า Express แล้วใช้มาตรฐานเดียวกับทุกระบบ (ซื้อ ขาย สมุดรายวัน การเงิน สต๊อก POS ฯลฯ)
3. **หน้าตาเหมือนกันทุกหน้า ทุกโปรแกรม** — ปุ่มเดียวกันอยู่ที่เดิม ชื่อเดิม ปุ่มลัดเดิม
4. **กันผิดตั้งแต่ตอนคีย์** — เตือนทันทีที่ช่อง ไม่ปล่อยให้ไปเจอข้อผิดพลาดตอนกดบันทึก
5. **ข้อมูลถูกต้องตามหลักบัญชีและภาษี** — หน้าจอสวยต้องไม่แลกกับความถูกต้อง

## 1. ปุ่มและแถบเครื่องมือ

- [ ] แถบเครื่องมือครบทุกหน้าเอกสาร: **+ ใหม่ (Alt+A/Insert) · แก้ไข (Alt+E) · บันทึก (F9/Ctrl+S) · ยกเลิกเอกสาร (Alt+C) · ลบ (Alt+D) · พิมพ์ (Alt+P) · หมายเหตุ (Alt+R) · รายละเอียด/ประวัติ (Ctrl+I) · ⏮ ◀ ▶ ⏭ · ปิดหน้าจอ (Alt+X) · กลับ (Esc)**
- [ ] ปุ่มหลัก (บันทึก) **หน้าละ 1 ปุ่ม** เด่นที่สุด อยู่ตำแหน่งแรก · ปุ่มอันตราย (ลบ/ยกเลิก) สีแดง อยู่ขวาสุด
- [ ] ปุ่มมี **ป้ายข้อความ + ปุ่มลัด** (เช่น "บันทึก F9") · ชี้เมาส์ขึ้นคำอธิบาย · มีแถบปุ่มลัดท้ายหน้า
- [ ] กดแล้ว **ปุ่มหมุนแสดงว่ากำลังทำงาน และกดซ้ำไม่ได้** (กันบันทึกซ้ำ)
- [ ] ปุ่มบนจอสัมผัสสูง ≥ 44 px · ปุ่มจอแคชเชียร์ ≥ 56 px
- [ ] ⏮◀▶⏭ ไปเอกสารชนิดเดียวกันเรียงตามเลขที่ · มีงานแก้ค้างต้องถามก่อนไป

## 2. การคีย์ข้อมูล — Enter พาไปจนจบการบันทึก

- [ ] **Enter = ช่องถัดไป** ตามลำดับที่ใช้งานจริง (ข้ามช่องที่ไม่ต้องคีย์) · **Shift+Enter = ย้อน** · ช่องหลายบรรทัด Enter ขึ้นบรรทัดใหม่
- [ ] เพิ่มใบใหม่ → **เคอร์เซอร์อยู่ช่องแรกทันที** (เช่น รหัสลูกค้า) · กดแก้ไข → ไปช่องแรกที่แก้ได้
- [ ] ตารางรายการ: Enter ไปทีละช่อง · แถวสุดท้าย = เพิ่มบรรทัดใหม่ · **บรรทัดว่างกด Enter = จบรายการ** ไปช่องถัดจากตาราง
- [ ] **ช่องสุดท้าย Enter → หน้าต่าง "คีย์ครบแล้ว — บันทึก?"** (Enter = บันทึก · บันทึก + ใบใหม่ · กลับไปแก้)
- [ ] **ช่องบังคับ (ป้าย \*) ว่าง กด Enter ไม่ผ่าน** — อยู่ช่องเดิม กรอบแดง เตือนติดช่อง · ถ้าเป็นช่องรหัส ให้เปิดรายการให้เลือกเลย
- [ ] เอกสารที่มีการรับ/จ่ายเงิน: ก่อนบันทึก **ถามวิธีรับ/จ่ายเงิน** (เงินสดทั้งจำนวน = Enter / วิธีที่ตั้งไว้ / แยกหลายวิธี) · ยอดไม่ครบต้องถาม
- [ ] ช่องที่กำลังคีย์มี **กรอบสีชัด** · ช่องกรอกทุกช่องมีเส้นขอบชัด
- [ ] ปิดหน้าต่าง/ออกจากหน้าที่ยังไม่บันทึก → **ถามยืนยันก่อน**

## 3. ช่องค้นหาและช่องเลือก

- [ ] **กล่องเดียว** พิมพ์ค้นและเลือกในกล่องเดียวกัน + ปุ่ม 🔍 ในกล่อง + **F4** เปิดรายการ
- [ ] ค้นได้ทั้ง รหัส ชื่อ เลขที่ เลขผู้เสียภาษี เบอร์โทร · ไม่สนเว้นวรรค/ตัวพิมพ์/ขีด · หลายคำไม่สนลำดับ
- [ ] ผลค้นหาแสดงข้อมูลรอง (เลขผู้เสียภาษี เบอร์โทร ยอดค้าง รูปสินค้า) ให้ตรวจก่อนเลือก · ลูกศร + Enter เลือกได้
- [ ] **ค้นไม่พบ → กด Insert เพิ่มรายการใหม่ได้จากหน้าต่างนั้นเลย** (เปิดแล้วอยู่ช่องรหัส) · ค่าที่เลือกไว้เดิมห้ามหาย
- [ ] ช่องที่ต้องมีเงื่อนไข แสดง **เฉพาะรายการที่ใช้ได้** (เช่น รับชำระหนี้ แสดงเฉพาะลูกค้าที่มีบิลค้าง พร้อมจำนวนบิล/ยอด) · เลือกแล้วใช้ไม่ได้ → เตือนทันที ล้างช่องให้เลือกใหม่
- [ ] **ค่าเริ่มต้น** เติมให้เห็นทันที: คลังหลัก · สำนักงานใหญ่ · วันนี้ (เวลาไทย) · ค่าจากครั้งก่อนของคู่ค้าเดิม

## 4. วันที่ ตัวเลข เงิน

- [ ] วันที่แสดง/รับ **วว/ดด/ปปปป พ.ศ.** ทุกเครื่อง (ตามระบบปีของบริษัท) · มีตัวอย่างรูปแบบ + ปุ่ม 📅 ปฏิทิน (F4/Alt+↓) · พิมพ์ได้หลายแบบ (12/10/2569 · 12102569 · 12/10/69 · ค.ศ.) · วันที่ไม่มีจริงไม่รับ
- [ ] "วันนี้" = **เวลาไทย** ห้ามใช้เวลาสากล
- [ ] เงิน **ชิดขวา คั่นหลักพัน ทศนิยม 2 ตำแหน่ง** ตัวเลขความกว้างคงที่ (฿1,250.00) · ขณะคีย์แสดงค่าดิบ เลือกทั้งช่องให้พิมพ์ทับ
- [ ] ส่วนลด: `200` = บาท · `5%` / `5+` = เปอร์เซ็นต์ · `5+2+` ซ้อน · `5+,200` = 5% แล้วลดอีก 200 · รูปแบบผิดเตือนทันที · คีย์จำนวนเงินเอง → คิดส่วนลด/ราคาให้

## 5. ข้อความแจ้ง

- [ ] ข้อความทั่วไป **กลางจอ ตัวใหญ่ สีตามชนิด** (✓ เขียว · ⚠ ส้ม · ✕ แดง) · ข้อความเกี่ยวกับช่อง **ติดที่ช่องนั้น**
- [ ] ข้อผิดพลาดบอก **เกิดอะไร + ต้องทำอะไรต่อ** (เช่น บอกเลขที่เอกสารที่ต้องยกเลิกก่อน) · ใช้ Message# ของ Express ถ้ามี
- [ ] สถานะมีคำกำกับเสมอ **ไม่ใช้สีอย่างเดียว**
- [ ] บอกตามจริง: เอกสารที่ไม่ลงบัญชีแจ้ง "(ไม่ลงบัญชี)" ไม่ใช่ "ลงบัญชีแล้ว"

## 6. หน้าจอเอกสาร

- [ ] เปิดเอกสารเดิม = **ดูอย่างเดียว** (ช่องพื้นเทา ป้ายบอก) → ต้องกด **แก้ไข** ก่อน · บันทึกแล้วกลับเป็นดูอย่างเดียว · "เลิกแก้ไข" ทิ้งการแก้
- [ ] **ยกเลิก ≠ ลบ**: ยกเลิก = ยังเห็น ป้ายแดง "เอกสารยกเลิก — เหตุผล" ตัวเลขขีดฆ่า ไม่ลงบัญชี · ลบ = เฉพาะที่ยกเลิกแล้ว ต้องมีสิทธิ์ + เหตุผล เลขที่ว่างให้ใช้ใหม่ · **เอกสารที่มีเอกสารอื่นอ้างถึง ยกเลิก/ลบไม่ได้** บอกว่าต้องจัดการใบไหนก่อน · ทุกการกระทำเก็บประวัติ
- [ ] ช่อง **เลขที่เอกสาร** แสดงตัวนำหน้า + ตัวอย่างเลขถัดไป · คีย์เองได้แต่ลบตัวนำหน้าไม่ได้ ห้ามซ้ำ · ไม่คีย์ = เลขอัตโนมัติ
- [ ] **มุมขวาบนบอกสาขา** ที่บันทึก (🏢) ทุกเอกสาร · รายงานแยก/รวมสาขาได้ หัวรายงานบอกสาขา
- [ ] แท็บ **"ตัวอย่างการลงบัญชี"** ตั้งแต่ใบใหม่ (Dr/Cr ตรงกับตอนบันทึกจริง) · บันทึกแล้ว = "ใบสำคัญที่ลงบัญชี" คลิกไปได้
- [ ] **แท็บข้อมูลที่เกี่ยวข้องคลิกดูได้เสมอ** แม้ยังไม่กดแก้ไข: ภาษีซื้อ/ขาย · ภาษีหัก ณ ที่จ่าย (พิมพ์ 50 ทวิ) · รับ/จ่ายชำระ · เช็ค · มัดจำ
- [ ] **เลขที่อ้างอิงทุกจุดเป็นลิงก์** เปิดเอกสารนั้นได้ · ถ้ากำลังคีย์ค้างให้เปิดแท็บใหม่ไม่ทิ้งงาน · Back กลับหน้าเดิม
- [ ] หมายเหตุ 2 แบบ: **เอกสาร** (Alt+R) และ **รายการ** (Alt+M ต่อบรรทัด หลายบรรทัด ติ๊กพิมพ์)
- [ ] เตือนเชิงธุรกิจตอนเลือกคู่ค้า: มีเงินมัดจำ → ถามจะหักไหม · เกินวงเงิน · ระงับการขาย/จ่าย (ป้ายแดง)
- [ ] ข้อมูลยาว **แบ่งแท็บย่อย** · ขนาดช่องและการจัดเรียงดูง่าย จัดกลุ่มตามลำดับการคีย์
- [ ] **ซื้อ+เจ้าหนี้ กับ ขาย+ลูกหนี้ หน้าตาและการทำงานเหมือนกัน** ต่างเฉพาะที่หลักบัญชี/ภาษีบังคับ

## 7. หน้ารายการ (List) และรายงาน

- [ ] แถวที่เลือกมีแถบสี · **คลิกได้ทุกแถว** เพื่อเปิด
- [ ] ค้นหา/กรอง (สาขา วันที่ สถานะ ประเภทคู่ค้า) · ส่งออก Excel/CSV · พิมพ์/PDF

## 8. ปุ่มปรับสไตล์หน้าจอ

- [ ] ปุ่ม **"สไตล์"**: ธีมพาสเทลหลายชุด/แถบสี · สีเน้น · **ขนาดตัวหนังสือ** · **แบบอักษร** · เห็นผลทันที
- [ ] จำตามผู้ใช้/เครื่อง · เจ้าของตั้งค่าเริ่มต้นของบริษัท/ร้านได้
- [ ] **ธีมพาสเทลสว่างเท่านั้น** ตาม Design System WTS · ทุกชุดสีผ่านเกณฑ์อ่านง่าย (WCAG)

## 9. ทุกขนาดจอ — คอม · iPad/แท็บเล็ต · มือถือ

- [ ] ตรวจที่กว้าง **375/390 · 768 · 1024 · 1440 px** — หน้าไม่เลื่อนซ้ายขวา ไม่มีอะไรโผล่เกินจอ
- [ ] มือถือ: ตารางกลายเป็นการ์ด หรือเลื่อนในกรอบตัวเอง · เมนู ☰ ใช้ได้ · แถบตัวกรองขึ้นบรรทัดใหม่ · หน้าต่างย่อยพอดีจอ
- [ ] จอสัมผัส: ปุ่มแตะง่าย ไม่ต้องพึ่งคีย์บอร์ด

## 10. แบบฟอร์มพิมพ์ (ใบเสร็จ ใบกำกับ ใบส่งของ ใบโอน ใบสั่ง ใบสำคัญ สรุปยอด ฯลฯ)

- [ ] **สวยแบบมืออาชีพ**: โลโก้ · ชื่อ/ที่อยู่กิจการ · เลขผู้เสียภาษี · **สาขา (เขียนแบบเดียวกันทุกใบ)** · กล่องลูกค้า/เลขที่ · ตารางหัวสีตามธีม · ยอดรวมเด่น · ยอดเป็นตัวอักษร · **ช่องเซ็นเป็นกรอบ + รูปลายเซ็น**
- [ ] ชื่อเอกสารถูกตามกฎหมาย/ภาษี + ชื่ออังกฤษ (เช่น ใบแจ้งหนี้/ใบกำกับภาษี · ใบเสร็จรับเงิน/ใบกำกับภาษี เมื่อภาษีเกณฑ์เงินสด)
- [ ] ขนาดกระดาษ: **A4** และ **กระดาษม้วน 80/58 มม.** (หน้าร้าน) · **ดูก่อนพิมพ์** · กดพิมพ์ต้องออกทุกครั้ง (มีปุ่มเปิดหน้าพิมพ์แท็บใหม่/บันทึก PDF)
- [ ] เลือกแบบสำเร็จรูป + แก้เอง (หัวเรื่อง คอลัมน์ ช่องลงชื่อ สำเนา ตำแหน่งโลโก้)
- [ ] **แบบฟอร์มราชการ** (50 ทวิ ภ.พ.30 ภ.ง.ด. ฯลฯ) ต้องเหมือนต้นฉบับของหน่วยงานทุกตัวอักษร
- [ ] เอกสารพิมพ์และข้อมูลของผู้ใช้ **ไม่แปลภาษาอัตโนมัติ**

## 11. ภาษา

- [ ] ข้อความทั้งหมดภาษาไทย ง่าย ชัด · ปุ่ม **EN/ไทย** สลับได้ทุกเมนูและข้อความ (เพิ่มข้อความใหม่ต้องแปลตามอภิธานศัพท์)
- [ ] ข้อมูลที่มีชื่ออังกฤษแสดงชื่ออังกฤษในโหมด EN

## 12. ช่องข้อมูลมาตรฐาน (ใช้แบบเดียวกันทุกโปรแกรม)

- [ ] **ที่อยู่**แยกช่อง (เลขที่ หมู่ หมู่บ้าน อาคาร ห้อง ชั้น ซอย ถนน) · จังหวัด→อำเภอ→ตำบลเลือกจากรายการ · รหัสไปรษณีย์เติมให้
- [ ] **คำนำหน้านาม** เลือกค่าเดียว (ไทย หรือ อังกฤษ) จากรายการมาตรฐาน
- [ ] **เลขผู้เสียภาษี** 13 หลักตรวจหลักตรวจสอบ · ห้ามซ้ำ (เลข+สาขาเดียวกัน) กรณีอื่นเตือน · สาขาว่าง = 00000 สำนักงานใหญ่
- [ ] รหัสข้อมูลหลักไม่ซ้ำ บอกว่าซ้ำกับรายไหน
- [ ] สินค้ามีบาร์โค้ด หมายเลขเครื่อง รูปภาพ (รูปเล็กในรายการและช่องค้นหา)

## ก่อนส่งงานหน้าจอ (ผู้ช่วยทำเองทุกครั้ง)

1. ไล่ข้อ 1–12 ข้างบนกับหน้าจอที่ทำ — ข้อไหนไม่เกี่ยวข้ามได้ ข้อไหนเกี่ยวแต่ยังไม่ทำต้องแจ้ง
2. **ลองใช้จริงในเบราว์เซอร์**ด้วยข้อมูลทดลอง: คีย์ด้วย Enter อย่างเดียวจนบันทึกได้ · ลองช่องบังคับว่าง · ลองค้นไม่พบแล้ว Insert · ลองพิมพ์
3. **ถ่ายภาพหน้าจอ** ที่ 375/768/1440 px + ตัวอย่างแบบฟอร์มพิมพ์ แล้วส่งให้เจ้าของดู
4. ทดสอบอัตโนมัติ + typecheck ผ่าน (ดู exit code) · งานที่กระทบยอดเงินคิดตัวเลขเทียบด้วยมือ
5. รายงานเจ้าของเป็นภาษาไทย: ทำอะไร · ลองอะไรแล้วได้ผลอะไร · อะไรยังไม่ได้ทำ/ยังไม่ได้ลอง · จบด้วยข้อความที่เจ้าของพิมพ์ต่อได้เลย

## วิธีทำงานกับเจ้าของ

- เจ้าของไม่ได้เขียนโปรแกรม — ผู้ช่วยทำงานเทคนิคเองทั้งหมด ถามเฉพาะเรื่องที่เจ้าของต้องตัดสินใจ/ทำเอง (พร้อมขั้นตอนทีละคลิก)
- ตัวเลือกให้เป็นปุ่มกด แนะนำอันแรก · เจ้าของส่งภาพหน้าจอวงแดงมา = แก้ตามจุดที่วง แล้วลองในเบราว์เซอร์ก่อนรายงาน
- เจ้าของสั่งเพิ่มเรื่องใหม่ที่ใช้กับทุกหน้าจอ → **เพิ่มลงไฟล์นี้** (และสถานะใน `docs/13`) ทันที เพื่อไม่ต้องสั่งซ้ำ
