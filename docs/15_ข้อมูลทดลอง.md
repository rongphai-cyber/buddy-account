# ข้อมูลทดลองบริษัท DEMO (ทั้งปี 2569)

อัปเดต: 30/10/2569

บริษัท **DEMO · บริษัท บัดดี้ เทรดดิ้ง (ทดลอง) จำกัด** เป็นข้อมูลสมมติทั้งหมด สร้างใหม่ทั้งปี 1 ม.ค. – 31 ธ.ค. 2569 ผ่านหน้าจอ/API ของโปรแกรมเอง
(กฎลงบัญชี ภาษี สต๊อก ตรวจครบเหมือนผู้ใช้คีย์จริง) — ข้อมูลที่ย้ายมาจาก Express (TESTRice) ชุดเดิมถูกลบออกจากฐานหลักแล้ว แต่ยังอยู่ในฐานสำรอง

## มีอะไรบ้าง
- ผังบัญชีไทย–อังกฤษ (`th_en`) · ปีบัญชี 2569 · ยอดยกมาต้นปี (บัญชี ลูกหนี้ เจ้าหนี้ สินค้า) · ยอดปีที่แล้ว 2568 สำหรับงบเปรียบเทียบ · งบประมาณ
- แฟ้มหลัก: ลูกค้า 25 · ผู้จำหน่าย 15 · พนักงานขาย 3 · สินค้า/บริการ/รหัสรายได้-ค่าใช้จ่าย 53 · สินค้าชุด · ราคาเสริม · หมายเลขสินค้า · ผู้ติดต่อ · แผนก 4 · คลัง 2 · บัญชีเงินฝาก 3 (BBL, KBANK, KTB) · ทรัพย์สิน 8
- งานทุกเดือน: เสนอราคา → ใบสั่งขาย → ขายเชื่อ/ขายสด → รับชำระ (เงินสด เงินโอน เช็ค) · ใบสั่งซื้อ → ซื้อ → จ่ายชำระ · ค่าใช้จ่ายอื่น/รายได้อื่น · มัดจำ · ลดหนี้/เพิ่มหนี้ · เบิก/โอน/ตรวจนับสต๊อก · เช็คผ่าน/เช็คคืน · กระทบยอดเงินฝาก · เงินสดย่อย · เงินเดือน (ต้นแบบบันทึก) · ค่าเสื่อม · ปิดภาษีมูลค่าเพิ่มรายเดือน · ภาษีหัก ณ ที่จ่าย
- เอกสารรวมประมาณ 1,500 ใบ (เช่น ขายเชื่อ 169 · ซื้อ 205 · รับชำระ 115 · จ่ายชำระ 70 · ใบสั่งซื้อ 177 · ค่าใช้จ่ายอื่น 92)
- ปิดงวด (ล็อค) ม.ค.–ก.ย. 2569 · ต.ค.–ธ.ค. ยังเปิด (ทดลองแก้/บันทึกได้) · ยังไม่ได้ประมวลผลสิ้นปี (ทดลองเองได้)
- แบบงบ "งบกำไรขาดทุนเทียบงบประมาณ" (PLBUD) · รายงานของผู้ใช้ · แบบฟอร์มพิมพ์ของบริษัท · คำขอ PDPA 2 รายการ
- เมนูที่ยังไม่มีข้อมูล (ตั้งใจ): กุญแจ API · เครื่องสาขา (ออฟไลน์)

## ผู้ใช้สำหรับทดลอง
- `admin` — ผู้ดูแล (เปิดยืนยันตัวตนสองขั้นแล้ว) รหัสผ่านใน `.data/ข้อมูลเข้าระบบ-ผู้ดูแล.txt`
- `sale1` (พนักงานขาย — เปิดสมุดรายวันไม่ได้) และ `acc1` (พนักงานบัญชี) รหัสผ่านใน `.data/ข้อมูลเข้าระบบ-ผู้ใช้ทดลอง.txt`
- `demo.seed` — ผู้ใช้ชั่วคราวสำหรับใส่ข้อมูล ปิดไว้แล้ว (สถานะเลิกใช้)

## สร้างข้อมูลใหม่ทั้งชุด (ถ้าต้องการล้างแล้วเริ่มใหม่)
ปิดโปรแกรมก่อน (พอร์ต 4100 ว่าง) แล้วทำตามลำดับ:
1. สำรองฐาน (ตั้งชื่อเอง เช่น buddy_backup_วันที่): `node tools/local-pg/pg.mjs run -- node tools/demo-check/db-backup.mjs save buddy_backup_20261231`
2. ลบบริษัท: `node tools/local-pg/pg.mjs run -- node tools/demo-check/wipe-company.mjs DEMO --yes`
3. เปิดผู้ใช้ใส่ข้อมูล: `node tools/local-pg/pg.mjs run -- node tools/demo-check/seed-user.mjs on`
4. เปิด server ชั่วคราว: `PORT=4102 BUDDY_REQUIRE_ADMIN_2FA=0 node tools/local-pg/pg.mjs run -- pnpm --filter @buddy/server start`
5. ใส่ข้อมูล (ประมาณ 2 นาที ตรวจ 13 ข้อท้ายสคริปต์): `SEED_LIVE=1 BASE=http://127.0.0.1:4102 node tools/local-pg/pg.mjs run -- node tools/demo-check/seed-year.mjs`
6. ปิดผู้ใช้ใส่ข้อมูล: `node tools/local-pg/pg.mjs run -- node tools/demo-check/seed-user.mjs off` แล้วปิด server ชั่วคราว เปิดโปรแกรมตามปกติ
