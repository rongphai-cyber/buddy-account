## 2. สิ่งที่ต้องเปลี่ยนเมื่อแยกเป็นโปรแกรมของตัวเอง
1. **ไม่ผูกโรงแรม** — ร้านนวด/เดย์สปาทั่วไปเป็นลูกค้าหลัก · "โรงแรม" เปลี่ยนเป็น "สาขา" · ลงเข้าห้องแขก = ส่วนเสริมภายหลังเมื่อมี WTS-Hotel
2. **ไม่ลงบัญชีเอง** — ส่งเอกสารเข้า Buddy ผ่าน Connector แบบเดียวกับ WTS-Living/WTS-POS (X-Source กันซ้ำ คิวส่งตามลำดับ ส่งใหม่อัตโนมัติ)
3. **ปิดวันทำการของสปาเอง** แทน Night Audit ของโรงแรม — สรุปยอด ค่ามือ ทิป แพ็กเกจหมดอายุ แล้วส่งเข้า Buddy
4. **ทำงานตอนเน็ตหลุดได้ (D11)** — หน้าเคาน์เตอร์: ดูตารางวันนี้ มาถึง/เสร็จ รับเงินสด ออกใบกำกับอย่างย่อ (เลขชุดของเครื่อง) ลงเข้างานของหมอ → เก็บในเครื่อง ส่งเมื่อเน็ตกลับ
5. **มาตรฐานหน้าจอ** ตาม `docs/18_มาตรฐาน UX-UI ทุกโปรแกรม WTS.md` ตั้งแต่งานแรก (แถบเครื่องมือ F9 Alt+C ⏮◀▶⏭ ค้นหา 🔍 วันที่ พ.ศ. มือถือ)
6. **เข้าระบบผ่าน Buddy** (บัตรผ่านจากหน้าเลือกโปรแกรม แบบ B6.1) · โมดูล `spa` มีใน Buddy แล้ว (B0.6) · การ์ด Spa "เร็ว ๆ นี้" บนหน้าเลือกโปรแกรมเปลี่ยนเป็นเปิดได้

## 4. การลงบัญชีใน Buddy (ร่าง — ทีมบัญชีตรวจ)
| เหตุการณ์ | เอกสารใน Buddy |
|---|---|
| ขายบริการ/สินค้า รับเงินแล้ว (ใบกำกับอย่างย่อ) | สรุปยอดขายประจำวันต่อสาขา (แบบ POS: abbreviated invoices + source_totals) แยกวิธีรับเงิน |
| ใบกำกับเต็มรูป | ใบกำกับ/ใบเสร็จรายใบ |
| ขายแพ็กเกจ (ระบุบริการ) | รับเงินล่วงหน้า + ภาษีขายตอนรับเงิน (ม.78/1) |
| ใช้แพ็กเกจ | ล้างรับล่วงหน้า → รายได้ (ไม่มี VAT ซ้ำ) |
| บัตรเงินสด/มัดจำ | เงินรับฝาก ไม่มี VAT ตอนขาย · VAT ตอนใช้ |
| หมดอายุ | แพ็กเกจที่เหลือ → รายได้สปา · บัตรเงินสดที่เหลือ → รายได้อื่น |
| ค่ามือ ประกันมือ ค่ารีเควส | Dr ค่าคอมมิชชั่นพนักงาน / Cr ค้างจ่าย · จ่ายเงินสด → ล้างค้างจ่าย · ทิปรับแทนหมอ = เงินรับแทน (ไม่ใช่รายได้) |
| คืนเงิน | ใบคืนเงิน ล้างเงินรับฝาก |

ต้องยืนยันกับผู้สอบบัญชี: VAT ของแพ็กเกจตอนขาย · บัตรเงินสดใช้ได้หลายบริการเป็นเงินรับฝาก · บัตรหมดอายุไม่มี VAT · Service Charge อยู่ในฐาน VAT · ค่ามือหมออิสระ/Outsource ต้องหัก ณ ที่จ่ายหรือไม่
