## ช่องของใบกำกับภาษีอย่างย่อ (ข้อ 1)

ต้องมี ("Must" ในแบบ):
- ชื่อบริษัท
- เลขประจำตัวผู้เสียภาษี + สำนักงานใหญ่/สาขาที่
- วันที่ และเลขที่เอกสาร (Doc No.)
- POS ID (เลขเครื่อง)
- หัวเรื่อง **"ใบเสร็จรับเงิน/ใบกำกับภาษีอย่างย่อ"** (อังกฤษ RECEIPT/TAX INVOICE (ABB))
- ตารางรายการ: Item · Qty · Price · Amount
- รวมทั้งสิ้น / Total (THB)
- ข้อความ "ราคานี้รวมภาษีมูลค่าเพิ่มแล้ว" (The above price includes Value Added Tax (VAT))

มีได้ (ไม่บังคับ): ที่อยู่ · โทร · อีเมล · เวลาจอง (Booking time) · มูลค่าก่อนภาษี / Value before VAT · ภาษีมูลค่าเพิ่ม 7% / VAT 7% ·
การรับชำระ (เงินสด / เงินโอน / Credit card / อื่น ๆ) และรายละเอียด · ขอบคุณที่ใช้บริการ / Thank you

ตัวอย่างในแบบ: Foot Massage with Balm 60 Mins × 1 = 700.00 → มูลค่าก่อนภาษี 654.21 · VAT 7% 45.79
