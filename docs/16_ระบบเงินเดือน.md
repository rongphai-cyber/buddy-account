## สูตร (packages/core/src/payroll.ts — ชุดทดสอบ payroll.test.ts ตัวเลขเดียวกับ WTS-ERP)
- ภาษี ป.96/2543: เงินได้ประจำ ประมาณทั้งปี = ที่จ่ายแล้ว + เดือนนี้ × ครั้งที่เหลือ (เริ่ม = เดือนที่เข้างานในปี · จบ = เดือนที่ออก) → ภาษีทั้งปี − ที่หักแล้ว ÷ ครั้งที่เหลือ · เงินได้ไม่ประจำ (OT โบนัส) = ภาษีส่วนเพิ่มเต็มจำนวนในเดือนที่จ่าย · ปัด 2 ตำแหน่งครึ่งขึ้น
- ผู้รับภาระภาษี W หัก ณ ที่จ่าย · O ออกให้ครั้งเดียว (บวกภาษีครั้งเดียว) · F ออกให้ตลอดไป (วนจนนิ่ง) · N ไม่หัก
- หลายรอบในเดือนภาษีเดียวกัน (รอบโบนัส): รวมยอดทั้งเดือนแล้วหักภาษี/ประกันสังคมที่รอบอื่นหักแล้ว
- เดือนภาษี = เดือนของวันที่จ่าย
- ประกันสังคม 5% ของค่าจ้าง (รายการที่ติ๊ก "นับเป็นค่าจ้างประกันสังคม") ฐาน 1,650–เพดาน ปัดเป็นบาท · เพดานตามวันที่: 15,000/750 (2568) · 17,500/875 (2569–2571) · 20,000/1,000 (2572) · 23,000/1,150 (2575) — ตรวจกับข่าวกฎกระทรวง 02/11/2569 · ลดหย่อนได้ไม่เกิน 12 × สูงสุดต่อเดือน
- กองทุนสำรองเลี้ยงชีพ: % ของค่าจ้างที่ติ๊ก "ฐานกองทุน" ต่อรอบ · ยอดลูกจ้างนับเป็นค่าลดหย่อนให้เอง (≤15% ≤500,000 กลุ่มเกษียณ)
- ค่าลดหย่อน ปีภาษี 2568–2569 (ALLOWANCES_2568) · กลุ่มชีวิต+สุขภาพ 100,000 · กลุ่มเกษียณ 500,000 · ThaiESG แยก · บริจาคการศึกษา 2 เท่า (10% ของเงินได้หลังลดหย่อน) แล้วบริจาคทั่วไป
- เงินเดือนรายเดือน: เต็มงวด = อัตราเต็ม · เข้า/ออก/ปรับกลางงวด = Σ อัตรา × วัน ÷ 30 (ตั้งค่าได้) · รายวัน/ชั่วโมง = จำนวน × อัตรา · OT/ขาดงาน/มาสาย = จำนวน × อัตรารายชั่วโมง/วัน (4 ตำแหน่ง) × ตัวคูณ
- ปีที่ยังไม่มีอัตราในโปรแกรม: ใช้ปีล่าสุดก่อนหน้าแล้วเตือนที่รอบเงินเดือน · บริษัทกำหนดแทนได้ (`pay_law`)

## การลงบัญชี
- บันทึก (POST /pay/runs/:id/post) = ออกเลขที่ `PY`+ปปดด+ลำดับ + ใบสำคัญ source_module PAY ในทรานแซกชันเดียว (แก้จากหน้าสมุดรายวันไม่ได้)
  Dr เงินได้แต่ละรายการตามแผนก (หักขาด/มาสายเป็นยอดลบ) + ประกันสังคม/กองทุนส่วนนายจ้าง + ภาษีที่บริษัทออกให้ · Cr ภาษีหัก ณ ที่จ่าย ภ.ง.ด.1 · ประกันสังคมรอนำส่ง (ลูกจ้าง+นายจ้าง) · กองทุนรอนำส่ง · เงินหักอื่น · เงินเดือนค้างจ่าย (สุทธิ)
- บัญชี = account_id ของรายการ หรือบทบาท PAY_* ใน gl_default_account (เริ่มระบบ › การเชื่อมต่อบัญชี หมวดเงินเดือน) · ผังตัวอย่าง th_en แมปให้ (5411-01, 2131-01, 2132-01, 2131-04 …) · บริษัทเดิม: ปุ่ม "เติมบัญชีจากผังตัวอย่าง" (เลขที่+ชื่อตรงกับผังตัวอย่างเท่านั้น ไม่ทับของเดิม) · บทบาทว่าง = ไม่ให้บันทึก (ไม่ลงบัญชีพัก)
- แก้ไข = เปิดกลับเป็นร่าง ใบสำคัญเดิมเป็น C → บันทึกใหม่ใช้ใบเดิมเลขเดิม (บรรทัดเก่าเก็บเป็นประวัติ)
- จ่าย = ใบสำคัญ `PA`+เลขเดียวกัน Dr เงินเดือนค้างจ่าย / Cr บัญชีที่เลือก · ยกเลิกการจ่าย = ใบจ่าย C
- ยกเลิก = C (จ่ายแล้วต้องยกเลิกการจ่ายก่อน) · ลบ = ร่างที่ยังไม่เคยบันทึก หรือรอบที่ยกเลิกแล้ว (deleted_at ทั้งชุดรวมใบสำคัญ)
- สมุดรายวัน: เส้นทาง PAYROLL / PAYROLL_PAY (เริ่มระบบ › การเชื่อมต่อบัญชี) → ไม่กำหนด = สมุด 00

## แบบฟอร์ม (ระยะ 2 — core `payroll-forms.ts`, server `modules/payroll/forms.ts`, หน้าจอ `pages/payroll/Forms.tsx`)
- ยอดจากรอบที่บันทึกแล้ว (N/P) เท่านั้น — มีร่างในช่วงนั้นแจ้งเตือน · ภ.ง.ด.1/สปส. เลือกสาขาที่ยื่นได้ (ว่าง = รวมทุกสาขา)
- เงินได้ใน ภ.ง.ด.1/1ก/50 ทวิ = ประจำ + ไม่ประจำ + ภาษีที่บริษัทออกให้ (เงินไม่ใช่เงินได้ไม่นับ) · เงื่อนไข 1 หัก ณ ที่จ่าย / 2 ออกให้ตลอดไป / 3 ออกให้ครั้งเดียว
- ภ.ง.ด.1ก และ 50 ทวิ รวมยอดยกมาต้นปี · 1ก ต้องมีที่อยู่ตามทะเบียนบ้านครบ (ตำบล อำเภอ จังหวัด รหัสไปรษณีย์) ไม่ครบแจ้งในรายการ "ต้องแก้ก่อนยื่น"
- 50 ทวิ: ปุ่ม "ออกเลขที่" ให้เลขถาวร (`pay_wht_cert` เล่มที่ = ปี พ.ศ. · เลขที่ลำดับตามรหัส · ออกซ้ำไม่เปลี่ยน) · พิมพ์บนแบบฟอร์มกรมสรรพากรตัวเดิม (`Wht50Sheet`) ฉบับที่ 1/2 · วันที่ออก = 31 ธ.ค. หรือวันที่ออกจากงาน
- สปส.1-10: ค่าจ้างในแบบไม่ต่ำ/ไม่เกินฐาน (1,650–17,500) · ค่าจ้างจริงเก็บไว้ทำแฟ้มยื่นในระยะ 3
- ใบแนบ ภ.ง.ด.1/1ก และ สปส.1-10 เป็นแบบพิมพ์ของโปรแกรม (หัวตาราง/ช่องตามแบบทางการ แต่ไม่ได้พิมพ์ทับภาพแบบฟอร์ม) — ถ้าเจ้าของต้องการทับแบบจริงให้ส่ง PDF แบบฟอร์ม (ทำแบบเดียวกับ 50 ทวิ)
- สลิป: A4 ได้ 2 ใบ · ยอดสะสมทั้งปี · โลโก้บริษัท · เลขบัตร/บัญชีแสดง 4 ตัวท้าย · พิมพ์บันทึก log PRINT
- PDPA: พนักงานเป็นเจ้าของข้อมูล (ค้นหา · รายงานข้อมูลรวมประวัติค่าจ้าง ค่าลดหย่อน เงินเดือนรายเดือน 50 ทวิ · ลบข้อมูลติดต่อ/บัญชีธนาคารทันที · ปิดบังทั้งหมดเมื่อพ้น 5 ปีนับจากจ่ายเงินเดือนครั้งล่าสุด)

## นำเข้า/ส่งออก/ยื่นแบบ (ระยะ 3 — core `payroll-files.ts` `payroll-import.ts`, server `modules/payroll/files.ts` `src/xls.ts` `src/xlsx.ts`, หน้าจอ `pages/payroll/Filing.tsx`)
- นำเข้าพนักงาน: แบบฟอร์ม .xlsx (แผ่น "พนักงาน" + "วิธีกรอก") · หัวตารางจับคู่ตามชื่อ (สลับลำดับได้) · รหัสเดิม = แก้เฉพาะช่องที่กรอก · รหัสใหม่ต้องมีชื่อ วันเริ่มงาน อัตราค่าจ้าง (ไม่มีวิธีคิดค่าจ้าง = รายเดือน) · ตรวจทั้งแฟ้มก่อน ผิดแถวเดียว = ไม่บันทึก · บันทึกผ่าน `saveEmployee` (กฎเดียวกับหน้าจอ) ในทรานแซกชันเดียว
- นำเข้ายอดงวด: แบบฟอร์มจากรอบ (รายชื่อในรอบ + คอลัมน์ "รหัส ชื่อรายการ (หน่วย)") · แถวที่กรอกแทนรายการป้อนเองเดิมของคนนั้น (source IMPORT) แล้วคำนวณใหม่ · เฉพาะรอบร่าง
- RD Prep: ไม่มีหัว คั่น | CRLF ทุกบรรทัด · UTF-8 หรือ TIS-620 · ภ.ง.ด.1 11 ช่อง / 1ก 21 ช่อง (ที่อยู่แยกส่วน) · ชื่อแฟ้ม PND1_<เลขผู้เสียภาษี>_<สาขา 6 หลัก>_<พ.ศ.>_<เดือน>_00_RDPrep.txt
- e-Filing FORMAT กลาง v2.0: H 22 ช่อง + D 26 ช่อง · CRLF ระหว่างบรรทัด ไม่มีท้ายแฟ้ม · ต้องตั้ง `pay.rd_efiling_user` (เฉพาะชื่อผู้ใช้ ห้ามรหัสผ่าน) · ยื่นเพิ่มเติม 1–9
- ตรวจก่อนสร้างแฟ้ม: เลข 13 หลักผ่าน check digit · มีนามสกุล · ไม่มีอักขระต้องห้าม (* + / \ ! $ % # & @ , ' " |) · 1ก ที่อยู่ครบ · e-Filing ที่อยู่ที่มีอักขระต้องห้ามเว้นว่าง
- แฟ้มประกันสังคม .xls (BIFF8 เขียนเองใน `src/xls.ts` — ตรวจด้วย Excel จริงแล้ว 03/11/2569): แผ่นงานชื่อ = ลำดับสาขา 6 หลัก · เลขบัตร (รูปแบบ 0000000000000) คำนำหน้า ชื่อ สกุล ค่าจ้างจ่ายจริง (ไม่ตัดเพดาน) เงินสมทบ · ชื่อแฟ้ม <เลขนายจ้าง>_<ดด><พ.ศ.>.xls · ข้อความใน SST
- ไฟล์โอนธนาคาร CSV (UTF-8 BOM): เฉพาะคนรับโอนที่ยอดสุทธิ > 0 · ไม่มีเลขบัญชี = ไม่สร้าง · รูปแบบเฉพาะธนาคารยังไม่ทำ
- การยื่น/นำส่ง (`pay_filing`, migration 0048): ภ.ง.ด.1 / ประกันสังคม / กองทุน = ใบสำคัญ PFปปดดนนนน Dr หนี้สินค้างจ่าย (+เงินเพิ่มเข้าบัญชีที่เลือก) / Cr เงินสด-เงินฝาก · ภ.ง.ด.1ก = บันทึกเท่านั้น · ยอดเริ่มต้นจากรอบที่บันทึกแล้ว · ยื่นปกติซ้ำงวดเดียวกันไม่ได้ (ยื่นเพิ่มเติม 1–9 ได้) · ยกเลิก = ใบสำคัญ C
- ล็อกเดือน: มีการยื่น ภ.ง.ด.1 หรือประกันสังคม (สถานะ A) ของเดือนภาษีนั้น → แก้/ยกเลิก/ลบรอบเงินเดือน (ที่บันทึกแล้ว) ไม่ได้ (`assertNotFiled`) · รอบใหม่/รอบร่างยังทำได้
- ⚠️ แฟ้มทุกชนิดยังไม่ได้ทดลองนำเข้าโปรแกรมของกรมสรรพากร/ประกันสังคมจริง — ต้องให้เจ้าของ/สำนักงานบัญชีลองก่อนยื่นครั้งแรก
