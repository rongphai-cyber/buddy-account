# ข้อกำหนดหลักของเจ้าของ — ตรวจทุกครั้งที่ทำหน้าจอ

ที่มา: `docs/ข้อกำหนดและที่จะต้องมีในโปรแกรม.docx` ของเจ้าของ (30/10/2569) ซึ่งตั้งเป็น **ข้อกำหนดหลักทุกครั้งที่เขียนโปรแกรม** โดยใช้หน้าจอขายเงินเชื่อของ Express เป็นต้นแบบ แล้วนำไปใช้กับระบบซื้อ ขาย สมุดรายวัน และระบบอื่นด้วย

สถานะ: ✅ มีแล้ว · 🆕 ทำเพิ่ม 30/10/2569 · 🟡 มีบางส่วน · ⬜ ยังไม่มี (รอเจ้าของจัดลำดับ)

## 1. การแสดงหน้าจอและการคีย์ข้อมูล

| ข้อกำหนด | สถานะ | ในโปรแกรม |
|---|---|---|
| แถบเครื่องมือครบ: เพิ่ม แก้ไข ยกเลิก ลบ บันทึก ปิด ค้นหา ประวัติการแก้ไข หมายเหตุ พิมพ์ การลงบัญชี | ✅ | แถบเครื่องมือทุกหน้าเอกสาร มี บันทึก F9 / ยกเลิกเอกสาร Alt+C / พิมพ์ Alt+P / 📝 หมายเหตุ Alt+R / ℹ รายละเอียดและประวัติ Ctrl+I / แท็บใบสำคัญที่ลงบัญชี / รายการ Esc |
| หมายเหตุ 2 แบบ แยกปุ่มและปุ่มลัด: **หมายเหตุเอกสาร** (ทั้งเอกสาร) · **หมายเหตุรายการ** (ต่อบรรทัด คีย์ตอนคีย์รายการ ติ๊กพิมพ์ได้) | 🆕 | **📄 หมายเหตุเอกสาร** (แถบเครื่องมือ · Alt+R) = หมายเหตุของทั้งเอกสาร พิมพ์ในกล่องหมายเหตุด้านล่างของเอกสาร · **📝 หมายเหตุรายการ** (ปุ่มในบรรทัด · Alt+M ขณะอยู่ในบรรทัด) = คีย์ได้หลายบรรทัดตอนคีย์รายการ (ก่อนบันทึกได้) ติ๊ก "พิมพ์" (ติ๊กไว้ให้) = พิมพ์เป็นบรรทัดใต้รายการนั้น · หน้าจอแสดงหมายเหตุใต้รายละเอียด (🖨 = พิมพ์) · ใช้กับ ขาย ซื้อ ใบเสนอราคา/ใบสั่ง ใบลด/เพิ่มหนี้ รับ/จ่ายเงินมัดจำ รายได้/ค่าใช้จ่ายอื่น รับ/จ่ายชำระหนี้ (ต่อบิล) เงินสดย่อย เอกสารสินค้า สมุดรายวัน · แก้เอกสารแล้วหมายเหตุรายการไม่หาย (เดิมหาย) |
| ยกเลิก กับ ลบ ต่างกัน (เจ้าของ 30/10/2569) · ปุ่ม **ลบ** และ **ปิดหน้าจอ** ทุกหน้าจอเอกสาร | 🆕 | **ยกเลิก** = เอกสารยังแสดงอยู่ มีป้ายแดง "เอกสารยกเลิก — เหตุผล" ข้างเลขที่ ตัวเลข/รายการขีดฆ่า ไม่ลงบัญชี ไม่นำยอดไปใช้ในรายงานใด · **ลบ** (🗑 Alt+D ต้องมีสิทธิ์ "ลบ") = เอกสารหายจากรายการ รายงาน บัญชีแยกประเภท เลขที่ว่างให้ใช้ใหม่ได้ — ยังไม่ยกเลิกระบบยกเลิกให้ก่อนแล้วลบในขั้นเดียว ต้องระบุเหตุผล · ลบไม่ได้ถ้ามีเอกสารอื่นที่ใช้งานอ้างถึง (เช่น ใบเสร็จที่ตัดบิล) · ประวัติการลบเก็บในบันทึกการทำงาน (หลักตรวจสอบ ห้ามลบประวัติ) · ใบสำคัญป้อนเองลบได้ ใบสำคัญจากเอกสารลบที่เอกสารต้นทาง · **ปิดหน้าจอ** (✕ Alt+X) กลับหน้าแรก |
| **กฎเหล็กการยกเลิก/ลบ:** เอกสารที่มีเอกสารอื่น (ที่ยังใช้งาน) อ้างถึงอยู่ ยกเลิกหรือลบไม่ได้ — ต้องแก้ไข/ยกเลิก/ลบเอกสารที่อ้างถึงก่อน | 🆕 | ตรวจที่ระบบกลาง (`usedBy`) ใช้ทั้งปุ่มยกเลิกและปุ่มลบ ข้อความบอกเลขที่เอกสารที่ต้องจัดการก่อน: บิลที่รับ/จ่ายชำระแล้ว (ใบเสร็จ/ใบสำคัญจ่าย) · ใบสั่งซื้อ/ขายที่ถูกอ้างในบิล · ใบเสนอราคาที่แปลงเป็นใบสั่งขาย · มัดจำที่ถูกหักในบิล · ใบกำกับที่อยู่ในใบวางบิล · ใบกำกับที่มีใบลด/เพิ่มหนี้อ้างถึง · ใบจ่ายเงินสดย่อยที่เบิกชดเชยแล้ว · ใบนำฝากที่มีเช็ค · เอกสารขายทรัพย์สิน |
| **ขายผ่านแพลตฟอร์มออนไลน์** (Grab LINE MAN Agoda Booking.com Airbnb ฯลฯ): ขายตั้งลูกหนี้ปกติ — ตอนรับชำระแพลตฟอร์มหักค่า GP/คอมมิชชั่น/ค่าธรรมเนียม/ค่าโฆษณาก่อนโอน ต้องลงค่าใช้จ่าย ภาษีซื้อ ภาษีหัก ณ ที่จ่าย และ ภ.พ.36 ให้ถูก | 🆕 | รับชำระหนี้ › แท็บ **หักโดยแพลตฟอร์ม (GP/ค่าธรรมเนียม)** (F8): เลือกผู้ให้บริการ (ผู้จำหน่าย) · รหัสค่าใช้จ่าย ค่าบริการก่อน VAT · VAT **1** ภาษีซื้อ 7% (ต้องมีเลขที่ใบกำกับ) / **3** ภ.พ.36 ผู้ให้บริการต่างประเทศ (เรานำส่งแทน ไม่ได้ถูกหัก) / **0** ไม่มี VAT · ภาษีหัก ณ ที่จ่ายที่เราหัก (ภ.ง.ด.53/3 ค่าบริการ/นายหน้า 3% โฆษณา 2%) เงื่อนไข 1 = รอเรียกคืนจากแพลตฟอร์ม / 3 = ออกให้ · คิด VAT/ภาษีหักให้เอง แก้ได้ · ผู้ให้บริการไม่มีเลขผู้เสียภาษีไทย = ต่างประเทศ (ภ.พ.36 ไม่หัก ณ ที่จ่าย) · ใบใหม่ของลูกค้าเดิมดึงรายการหักแบบครั้งก่อนให้ · ท้ายบิลแสดงยอดที่ถูกหัก เงินที่ได้รับจริง = ยอดบิล − ยอดที่ถูกหัก · ลงบัญชี Dr เงินที่ได้รับ + ค่าใช้จ่าย + ภาษีซื้อ / Cr ลูกหนี้ (ภ.พ.36: Dr ภาษีซื้อรอเครดิต / Cr ภาษีมูลค่าเพิ่มค้างจ่าย ภ.พ.36 · ภาษีหัก ณ ที่จ่าย: Cr ภาษีหัก ณ ที่จ่ายค้างจ่าย / Dr ภาษีรอเรียกคืน) · เข้าแฟ้มภาษีซื้อ แฟ้ม ภ.ง.ด.53/3 (พิมพ์ 50 ทวิ ได้) · รายงานภาษี **6.7 แบบ ภ.พ.36** (ยื่น/ชำระภายในวันที่ 7 เดือนถัดไป) · ภ.พ.36 เป็นภาษีซื้อใน ภ.พ.30 และใบปรับปรุงภาษีประจำเดือนของเดือนถัดไปอัตโนมัติ · บัญชีใหม่ 3 บัญชีที่ เริ่มระบบ › บัญชีเพื่อลงรายวัน (ผูกให้แล้วถ้าผังมาตรฐาน) |
| แพลตฟอร์ม (Grab LINE MAN Lazada Shopee …) หักหลายอย่าง — ค่า GP ค่าการตลาด ค่าโฆษณา ค่าธรรมเนียมอื่น — **การเชื่อมต่อบัญชีตั้งที่การตั้งค่าเอกสาร** | 🆕 | เริ่มระบบ › เลขที่เอกสาร (ประเภทเอกสารหมวด RE) › ส่วน **รายการหักโดยแพลตฟอร์ม**: ผู้ให้บริการของประเภทนั้น + รายการหัก (ชื่อ · เลขที่บัญชีค่าใช้จ่าย · VAT 1/3/0 · ประเภทเงินได้/อัตราหัก ณ ที่จ่าย) · ปุ่ม **ใส่รายการที่พบบ่อย** (ค่า GP/คอมมิชชั่น ค่าการตลาด/ส่งเสริมการขาย ค่าโฆษณา 2% ค่าธรรมเนียมการชำระเงิน ค่าขนส่ง 1% ค่าบริการอื่น — หาบัญชีค่าใช้จ่ายจากผังให้) · แนะนำแยกประเภทต่อแพลตฟอร์ม (เช่น RG รับชำระ Grab · RS รับชำระ Shopee) · ใบเสร็จใหม่ของประเภทนั้นดึงรายการทั้งหมดมาให้ ป้อนเฉพาะยอด รายการไม่มียอดไม่บันทึก · ลงค่าใช้จ่ายแยกบัญชีตามที่ตั้ง · บัญชีที่ใช้ในรายการหักลบจากผังไม่ได้ |
| หน้าตัดชำระ (รับชำระหนี้ · จ่ายชำระหนี้ · ใบวางบิล · ใบรับวางบิล): ค้นหาคู่ค้าแสดง**เฉพาะรายที่มีบิลค้าง** พร้อมจำนวนบิลและยอดค้าง · รายที่ไม่มีบิลค้างเลือกไม่ได้ เตือนทันที ไม่ปล่อยให้ทำต่อ | 🆕 | รายชื่อในช่องรหัสลูกค้า/ผู้จำหน่ายแสดง "ค้าง N ใบ · ยอด" ต่อท้าย · ไม่แสดงรายที่ไม่มีบิลค้าง (ค้นรหัสตรงก็ไม่พบ) · ไม่มีปุ่มเพิ่มรายใหม่จากช่องนี้ · ถ้าเลือกแล้วไม่มีบิลให้ตัด/วาง (เช่น วางบิลไปหมดแล้ว) เตือนกลางจอและล้างช่องให้เลือกรายอื่น — ไม่ต้องรอกดบันทึกแล้วเจอข้อผิดพลาด |
| รับชำระหนี้/จ่ายชำระหนี้: บิลค้าง**ขึ้นเป็นหน้าต่างให้เลือก** (ติ๊ก + ยอดที่จะชำระ) กด F5/ตกลง แล้วบิลที่เลือกจึงอยู่ในเอกสาร · บิลที่ลงวันที่หลังวันที่รับ/จ่ายเงินตัดได้แต่ต้องเตือน | 🆕 | เลือกลูกค้า/ผู้จำหน่ายแล้วเปิดหน้าต่าง "เลือกบิลค้างรับ/จ่ายชำระ" ทันที (ค้นเลขที่บิล/ใบวางบิล · เลือกทั้งหมด · ค่าเริ่มต้นยอดคงค้างเต็ม แก้ได้ · รวมยอดที่เลือก) · F5 = ตกลง (ในเอกสาร F5 = เปิดหน้าต่างอีกครั้ง บิลที่เลือกไว้ติ๊กอยู่) · ตารางในเอกสารมีเฉพาะบิลที่เลือก ✕ เอาออกได้ · บิลวันที่หลังวันที่รับ/จ่ายเงิน: ⚠ ในหน้าต่างและตาราง + กล่องเตือนเหนือรายการ + ถามยืนยันตอนบันทึก (ตัดได้ — รายงานหนี้คงเหลือ ณ วันที่ก่อนบิลเกิดอาจคำนวณผิด) |
| พิมพ์ใบเสร็จ: เลือกแสดง**เลขที่บิล** หรือ**รายการสินค้า/บริการของทุกบิล** · ใบเสร็จ 2 แบบ: **ใบเสร็จรับเงิน** (ใบกำกับภาษีออกตอนขายแล้ว) และ **ใบเสร็จรับเงิน/ใบกำกับภาษี** (ภาษีเกณฑ์เงินสด ถึงกำหนดเมื่อรับเงิน) · กดพิมพ์ต้องออก | 🆕 | ระบบเลือกชื่อเอกสารเอง: ตัดบิลภาษีเกณฑ์เงินสด → "ใบเสร็จรับเงิน/ใบกำกับภาษี" (RECEIPT / TAX INVOICE) แสดงรายการสินค้า/บริการ + แยก มูลค่าสินค้า/บริการ และภาษีมูลค่าเพิ่มที่ถึงกำหนด · อื่น ๆ → "ใบเสร็จรับเงิน" (RECEIPT) แสดงเลขที่บิล · จ่ายชำระหนี้ = "ใบสำคัญจ่าย" · เมนูพิมพ์มีแบบที่ 5 "แสดงรายการสินค้า/บริการของบิล" · ตั้งค่าแบบฟอร์ม › "รายการในใบเสร็จ" (อัตโนมัติ/เลขที่บิล/รายการสินค้า) · ระบบพิมพ์เก็บแผ่นเอกสารไว้จนพิมพ์เสร็จ (เดิมบางเบราว์เซอร์ได้หน้าว่าง) · หน้าดูทางจอภาพมีปุ่ม "เปิดหน้าพิมพ์ในแท็บใหม่" (พิมพ์/บันทึก PDF ได้เสมอ) · ตรวจกดพิมพ์ครบ 28 ชนิดเอกสาร + ใบสำคัญ |
| เงินสดย่อยอยู่เมนู**การเงิน** · **ลงบัญชีตอนจ่าย**: ใบจ่ายเงินสดย่อย (DP) Dr ค่าใช้จ่าย / Cr เงินสดย่อย · ใบเบิกชดเชย (VR) Dr เงินสดย่อย / Cr เงินสด-ธนาคาร ตามที่เบิก | 🆕 | การเงิน › เงินสดย่อย › DP / VR · บันทึกใบจ่ายแล้วลงบัญชีทันที (แท็บใบสำคัญที่ลงบัญชี) · ใบเบิกลงบัญชีล้างเงินสดย่อยตามยอดที่เบิก จ่ายเงินสด/เช็ค/โอนตามวิธีที่เลือก · บัญชีเงินสดย่อย = บัญชีเพื่อลงรายวัน "เงินสดย่อย" หรือช่องที่ 1 ของประเภทเอกสาร (หลายวงเงินแยกบัญชีได้) · ใบจ่ายเดิมที่ยังไม่ลงบัญชีถูกลงบัญชีให้ตอนบันทึกใบเบิก (ค่าใช้จ่ายไม่ตกหล่น) |
| เอกสารที่บันทึกแล้วต้องกดปุ่ม "แก้ไข" ก่อนจึงแก้ได้ | 🆕 | ทุกหน้าเอกสารและใบสำคัญ: เปิดเอกสารเดิมมาแบบ **ดูอย่างเดียว** (ช่องพื้นเทา ป้าย "ดูอย่างเดียว — กด แก้ไข (Alt+E)") · ปุ่ม **แก้ไข Alt+E** ถัดจากปุ่มบันทึก · บันทึกการแก้ไขแล้วกลับเป็นดูอย่างเดียว · กด "เลิกแก้ไข" = ทิ้งการแก้ไข · ยกเลิกเอกสาร/พิมพ์/หมายเหตุ ทำได้โดยไม่ต้องกดแก้ไข |
| ปุ่มไปรายการแรก ก่อนหน้า ถัดไป สุดท้าย | 🆕 | ปุ่ม ⏮ ◀ ▶ ⏭ ในแถบเครื่องมือทุกหน้าเอกสารและใบสำคัญ (ชนิด/สมุดเดียวกัน เรียงตามเลขที่) ถ้ามีการแก้ไขค้างอยู่จะถามก่อนไป |
