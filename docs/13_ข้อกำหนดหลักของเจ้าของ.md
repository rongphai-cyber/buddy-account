# ข้อกำหนดหลักของเจ้าของ — ตรวจทุกครั้งที่ทำหน้าจอ

ที่มา: `docs/ข้อกำหนดและที่จะต้องมีในโปรแกรม.docx` ของเจ้าของ (30/10/2569) ซึ่งตั้งเป็น **ข้อกำหนดหลักทุกครั้งที่เขียนโปรแกรม** โดยใช้หน้าจอขายเงินเชื่อของ Express เป็นต้นแบบ แล้วนำไปใช้กับระบบซื้อ ขาย สมุดรายวัน และระบบอื่นด้วย

สถานะ: ✅ มีแล้ว · 🆕 ทำเพิ่ม 30/10/2569 · 🟡 มีบางส่วน · ⬜ ยังไม่มี (รอเจ้าของจัดลำดับ)

## 1. การแสดงหน้าจอและการคีย์ข้อมูล

| ข้อกำหนด | สถานะ | ในโปรแกรม |
|---|---|---|
| แถบเครื่องมือครบ: เพิ่ม แก้ไข ยกเลิก ลบ บันทึก ปิด ค้นหา ประวัติการแก้ไข หมายเหตุ พิมพ์ การลงบัญชี | ✅ | แถบเครื่องมือทุกหน้าเอกสาร มี บันทึก F9 / ยกเลิกเอกสาร Alt+C / พิมพ์ Alt+P / 📝 หมายเหตุ Alt+R / ℹ รายละเอียดและประวัติ Ctrl+I / แท็บใบสำคัญที่ลงบัญชี / รายการ Esc |
| ปุ่มไปรายการแรก ก่อนหน้า ถัดไป สุดท้าย | 🆕 | ปุ่ม ⏮ ◀ ▶ ⏭ ในแถบเครื่องมือทุกหน้าเอกสารและใบสำคัญ (ชนิด/สมุดเดียวกัน เรียงตามเลขที่) ถ้ามีการแก้ไขค้างอยู่จะถามก่อนไป |
| ค้นหาได้ทั้งพิมพ์ในช่องและคลิกแว่นขยาย (รหัส ชื่อ เลขที่ เลขผู้เสียภาษี) | ✅ | ช่องเลือกคู่ค้า/สินค้า/บัญชี มีปุ่ม 🔍 และกด F4 ได้ |
| วันที่: แสดงตัวอย่างรูปแบบ และมีปฏิทินให้เลือก | ✅ | ช่องวันที่แสดง "วว/ดด/ปปปป" มีปุ่ม 📅 ปฏิทิน (F4 / Alt+↓) และรับ พ.ศ./ค.ศ. ตามบริษัท |
| แถบสีบอกช่องที่กำลังคีย์ · Enter ไปช่องถัดไปตามลำดับจนบันทึก | ✅ | ช่องที่เลือกอยู่มีกรอบสี · Enter ไปช่องถัดไป |
| ช่องที่ต้องมี ห้ามว่าง: เตือนและให้เลือก · ค้นหาไม่พบให้เพิ่มรายการใหม่ได้ | ✅ 🆕 | 🆕 ช่องเลขที่บัญชีในใบสำคัญ: กด Enter ตอนว่างจะเปิดหน้าต่างเลือกบัญชี (กด Insert เพื่อเพิ่มบัญชีใหม่) · ช่องบังคับอื่นตรวจตอนบันทึกพร้อมบอกช่องที่ผิด · 🆕 ช่องค้นหาลูกค้า/ผู้จำหน่าย/สินค้า (ทุกหน้าจอ): ค้นไม่พบ → กด Enter หรือ Insert หรือคลิก "＋ เพิ่ม…ใหม่" → ฟอร์มเดียวกับหน้าข้อมูลหลัก (สิ่งที่พิมพ์ไว้เติมเป็นรหัสหรือชื่อให้) → บันทึกแล้วเลือกให้ในเอกสารทันที · แสดงเฉพาะผู้มีสิทธิ์เพิ่มในเมนูนั้น |
| หมายเหตุรายการสินค้า (พิมพ์ด้วย หลายบรรทัด) | ✅ | หมายเหตุบรรทัด/เอกสาร Alt+R พิมพ์ในแบบฟอร์ม |
| ลูกค้ามีเงินมัดจำ: เตือนให้หัก (ตัดบางส่วน/เต็มได้ เกินไม่ได้ เงื่อนไขภาษีต้องเหมือนกัน) | 🆕 | เลือกคู่ค้าที่มีมัดจำคงเหลือ → ระบบถามว่าจะหักในบิลนี้หรือไม่ แล้วพาไปแท็บหักเงินมัดจำ (ตรวจยอดไม่เกินคงเหลือและประเภทราคาต้องตรงกัน) |
| ส่วนลดท้ายบิลเฉลี่ยลงทุกรายการ (รายงานยอดขายตามสินค้า) | ✅ | คำนวณยอดสุทธิของแต่ละบรรทัดหลังเฉลี่ยส่วนลดท้ายบิล รายงานวิเคราะห์ขายใช้ยอดนี้ |
| ขนาดและการจัดเรียงช่องให้ดูง่าย | 🟡 | ปรับต่อเนื่องทุกหน้าจอ |
| แท็บตรวจสอบ/คลิกไปแก้ข้อมูลที่เกี่ยวข้อง (แฟ้มภาษีขาย รายการรับชำระ) | ✅ 🆕 | เอกสารซื้อขายมีแท็บภาษี ภาษีหัก ณ ที่จ่าย รับ/จ่ายชำระ ใบสำคัญ · 🆕 **สมุดรายวันมีแท็บ ภาษีซื้อ / ภาษีขาย / ภาษีหัก ณ ที่จ่าย / เช็คจ่าย / เช็ครับ ตลอดเวลา รวมใบสำคัญใหม่** แต่ละแท็บแสดงยอดบรรทัดบัญชีนั้น ป้อนรายละเอียดก่อนบันทึกได้ (บันทึกพร้อมใบสำคัญในครั้งเดียว) ถ้าบันทึกโดยยังไม่ป้อน ระบบจะถาม |
| รายการสินค้า: รหัส (ค้นหา/เพิ่ม) คลัง จำนวน หน่วย ราคา ส่วนลด เลือกมี/ไม่มี VAT รายบรรทัด | ✅ | ตารางรายการมีครบทุกช่อง รวม "ไม่มี VAT" รายบรรทัด (บิลเดียวมีทั้งมีและไม่มี VAT ได้) · 🆕 เพิ่มสินค้า/บริการ/รายได้-ค่าใช้จ่ายอื่นใหม่จากช่องรหัสในบรรทัดได้ (ชนิดตามช่องนั้น) |
| ค่าเริ่มต้น เช่น คลังหลัก สำนักงานใหญ่ | ✅ | คลังของบรรทัด → หัวเอกสาร → คลังหลักของบริษัท · สาขาเริ่มต้น = สำนักงานใหญ่ |

## 2. การทำงานของระบบ

| ข้อกำหนด | สถานะ | ในโปรแกรม |
|---|---|---|
| รหัสข้อมูลหลักไม่ซ้ำ (สินค้า ลูกหนี้ ตัวนำหน้าเลขที่ เลขที่เอกสาร) · ช่องบังคับไม่ใส่บันทึกไม่ได้ | ✅ | ฐานข้อมูลบังคับไม่ซ้ำ และระบบบอกว่าซ้ำกับอะไร |
| เลขผู้เสียภาษีไม่ซ้ำ | ⬜ | **ต้องตัดสินใจ:** Express ยอมให้ซ้ำ เพราะบริษัทเดียวมีหลายสาขา (เลขเดียวกัน คนละสาขา) และเป็นทั้งลูกค้าและผู้จำหน่ายได้ — แนะนำให้ห้ามซ้ำเฉพาะเลข + สาขาเดียวกันในลูกค้า (หรือในผู้จำหน่าย) และให้เตือนในกรณีอื่น |
| ระบบวันที่/เวลาเหมือนกันทุกที่ (พ.ศ./ค.ศ.) | ✅ | เก็บวันที่แบบเดียวกันในฐานข้อมูล แสดงตามระบบปีของบริษัท เวลาใช้เวลาไทย |
| รายการ (List) มีแถบสีแถวที่เลือก คลิกเพื่อเปิด/แก้ | ✅ | ทุกตารางรายการคลิกแถวเพื่อเปิด |
| หน้าจอข้อมูลยาวแบ่งเป็นแท็บย่อย | ✅ | เอกสาร ลูกค้า สินค้า ใบสำคัญ แบ่งแท็บ |
| ใช้ผ่านมือถือ / iPad / จอสัมผัสได้ | 🟡 | หน้าจอปรับตามขนาดจอ (smoke ตรวจใบสำคัญบนจอมือถือ) — ยังไม่ได้ตรวจครบทุกหน้า |
| ปุ่มลัด: เอาเมาส์ชี้แล้วแสดง หรือแสดงไว้ให้เห็น | ✅ | ปุ่มมีป้ายปุ่มลัด และแถบปุ่มลัดท้ายหน้า |
| คำแนะนำในกล่องกรอก | 🟡 | มีในช่องสำคัญ (ตัวอย่างรูปแบบ คำอธิบายใต้ช่อง) |
| เปลี่ยนสี/ฟอนต์/ธีมของแต่ละบริษัท | ⬜ | ยังไม่มี |
| ออกแบบเอกสาร (ใบสำคัญ ใบเสร็จ ใบกำกับ ใบส่งของ) สำเร็จรูป + แก้เอง + โลโก้ + ลายเซ็น | ✅ 🆕 | แบบสำเร็จรูป 1–4 และตัวแก้แบบฟอร์ม (หัวเรื่อง คอลัมน์ ช่องลงชื่อ สำเนา) · 🆕 รายงาน › แบบฟอร์มพิมพ์เอกสาร › **โลโก้และลายเซ็นของบริษัท**: อัปโหลดโลโก้ 1 รูป + ลายเซ็นตั้งชื่อได้หลายรูป (PNG/JPG ใหญ่ย่อให้เอง ≤ 300 KB) · แต่ละแบบฟอร์มเลือกตำแหน่งโลโก้ (ซ้าย/กลาง/ขวา/ไม่แสดง) ความสูง และรูปลายเซ็นของแต่ละช่องลงชื่อ · ลบลายเซ็น = ล้างรูปจริง (ข้อมูลส่วนบุคคล) |
| พิมพ์หลายเครื่องพิมพ์ / PDF / ส่งออก Excel | ✅ | พิมพ์ผ่านหน้าต่างพิมพ์ (เลือกเครื่องหรือบันทึก PDF ได้) · รายงานส่งออก Excel/CSV |
| นำเข้า/เชื่อมต่อข้อมูลภายนอก โดยเฉพาะจาก Express | ✅ 🟡 | นำเข้า Express ทั้งบริษัท · API ให้ระบบอื่น · AI อ่านบิลซื้อ · ⬜ นำเข้ารายการขาย/ซื้อจากแฟ้ม Excel |
| 2 ภาษา (อังกฤษ) สลับได้ทุกเมนูและทุกข้อความ | ⬜ | ยังไม่มี (เป็นงานใหญ่ ต้องแปลทุกหน้าจอ/ข้อความ) |
| สินค้ามีบาร์โค้ด หมายเลขเครื่อง (Serial) รูปภาพ | 🟡 | บาร์โค้ด ✅ ทะเบียนหมายเลขสินค้า ✅ · ⬜ รูปภาพสินค้า |

## 3. การใช้งานกับลูกค้า

| ข้อกำหนด | สถานะ | ในโปรแกรม |
|---|---|---|
| หลายบริษัท ข้อมูลไม่ปนกัน | ✅ | แยกระดับลูกค้าผู้ใช้บริการและบริษัท + Row-Level Security ในฐานข้อมูล |
