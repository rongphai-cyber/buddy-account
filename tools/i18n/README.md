# สลับ 2 ภาษา (ไทย / อังกฤษ)

ข้อกำหนดเจ้าของข้อ 9 — "2 ภาษา (อังกฤษ) สลับได้ทุกเมนูและทุกข้อความ"

## หลักการ
- โค้ดเขียนข้อความเป็นภาษาไทยเหมือนเดิม (ภาษาไทยคือต้นฉบับ) — **ไม่ต้องห่อข้อความด้วยฟังก์ชันแปล**
- เลือก EN (ปุ่มที่แถบบน/หน้าเข้าระบบ จำไว้ในเครื่อง) → `apps/web/src/i18n.ts` แปลข้อความที่แสดงบนหน้าจอด้วยพจนานุกรม
  `apps/web/src/i18n/en.json` (โหลดเฉพาะเมื่อเลือกอังกฤษ) รวมข้อความแจ้งเตือน/ข้อผิดพลาดที่มาจาก server
- ตัวจับคู่อยู่ใน `packages/core/src/i18n.ts` (`makeTranslator`): ตรงตัว + แบบมีช่องแทน `{0}` (ค่าที่แทนเป็นคำไทยในพจนานุกรมก็แปลด้วย)
- **ไม่แปล**: ช่องกรอก (สิ่งที่ผู้ใช้พิมพ์), เอกสารพิมพ์ (ใช้ภาษาตามแบบฟอร์ม — ใบกำกับภาษีต้องเป็นไปตามกฎหมาย), ส่วนที่ติด `data-no-i18n`
- ข้อมูลของผู้ใช้ (ชื่อลูกค้า ชื่อบัญชี) แสดงตามที่บันทึก

## เพิ่ม/แก้ข้อความ
1. เขียนหน้าจอเป็นภาษาไทยตามปกติ
2. `python tools/i18n/extract.py` → `tools/i18n/catalog.json` (ข้อความไทยทุกจุดในโค้ด)
3. แปลข้อความใหม่ใส่ `tools/i18n/extra.json` (หรือชุดใน `tools/i18n/out/`) ตามอภิธานศัพท์ `tools/i18n/glossary.md`
4. `python tools/i18n/merge.py` → ตรวจช่องแทน/ค่าว่าง/ภาษาไทยค้าง แล้วเขียน `apps/web/src/i18n/en.json`
5. ตรวจหน้าจอจริง: `PASS=… BASE=… OUT=… node tools/demo-check/i18n-sweep.cjs` — รายการข้อความไทยที่ยังเหลือในโหมด EN
