# อภิธานศัพท์ ไทย → อังกฤษ (Buddy Account)

ใช้คำเหล่านี้ให้ตรงกันทุกที่ — โปรแกรมบัญชีไทยสำหรับ SME (เทียบโปรแกรม Express) ผู้อ่านคือนักบัญชี

## หลักการเขียน
- ภาษาอังกฤษแบบอเมริกัน กระชับแบบปุ่ม/ป้ายในโปรแกรม
- ป้ายสั้น (ชื่อเมนู ชื่อหน้า หัวคอลัมน์ ปุ่ม ≤ 5 คำ ไม่มีเครื่องหมายจบประโยค) → Title Case เช่น "Sales Invoice", "Save", "Due Date"
- ประโยค/คำแนะนำ/ข้อผิดพลาด → Sentence case และคงเครื่องหมาย — · ( ) : ตามต้นฉบับ
- คงไว้ตามเดิม: ช่องแทน {0} {1} (ห้ามเปลี่ยนเลข ห้ามตัดทิ้ง ย้ายตำแหน่งได้ตามไวยากรณ์), ปุ่มลัด (F4 F9 Ins Esc Alt+C Ctrl+S Enter), รหัส (IV RR HS JV ภ.ง.ด.3 → PND 3), ตัวเลข/เลขข้อ "1." "5.3", สัญลักษณ์และอีโมจิ (🔍 ⏮ ◀ ▶ ⏭ ✓ ✕ ⬆ ⬇ ＋)
- ข้อความที่เป็นชื่อเฉพาะ/ภาษาอังกฤษอยู่แล้ว (Express, Claude, PDF, Excel, CSV, XML, e-Tax, PDPA, API, 2FA) คงเดิม
- "บาท" → "baht" (กลางประโยค) · พ.ศ. → B.E. · ค.ศ. → A.D. · วว/ดด/ปปปป → DD/MM/YYYY
- อย่าแปลข้อความตัวอย่างที่เป็นข้อมูลไทย (เช่น ชื่อบริษัทตัวอย่างในวงเล็บ "เช่น บริษัท ก จำกัด") — แปลคำว่า "เช่น" เป็น "e.g." และคงตัวอย่างหรือแปลเป็นตัวอย่างอังกฤษก็ได้
