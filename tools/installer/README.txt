Buddy Account รุ่น {version}
===========================

ติดตั้ง
  ดับเบิลคลิกไฟล์ BuddyAccount-....exe (หรือแตกไฟล์ zip แล้วคลิกขวา install.ps1 > Run with PowerShell)
  ไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง · ไม่ต้องลงโปรแกรมอื่นเพิ่ม (มีฐานข้อมูล PostgreSQL 16 ในชุดแล้ว)

เปิดใช้งาน
  ไอคอน "Buddy Account" บนหน้าจอหรือเมนู Start → เบราว์เซอร์เปิดหน้าโปรแกรมให้เอง
  ครั้งแรก: ตั้งรหัสผู้ใช้และรหัสผ่านของผู้ดูแลระบบ แล้วสร้างบริษัท
  ระหว่างใช้งานจะมีหน้าต่างสีดำย่ออยู่ที่แถบงาน — ปิดหน้าต่างนั้น = ปิดโปรแกรม

ที่เก็บข้อมูล
  %LOCALAPPDATA%\BuddyAccount  (เมนู Start > Buddy Account > โฟลเดอร์ข้อมูล)
  อัปเดตรุ่นใหม่หรือถอนการติดตั้ง ข้อมูลยังอยู่ · สำรองข้อมูลที่ ตั้งค่า > สำรอง/นำกลับข้อมูล ในโปรแกรม

ให้เครื่องอื่นในวง LAN ใช้ด้วย
  แก้ไฟล์ config.json ในโฟลเดอร์ข้อมูล: "host": "0.0.0.0" แล้วเปิดโปรแกรมใหม่
  เครื่องอื่นเข้า http://<เลข IP เครื่องนี้>:4100 (Windows อาจถามอนุญาตไฟร์วอลล์ — กดอนุญาตเฉพาะเครือข่ายส่วนตัว)

มีปัญหา
  ดูบันทึกที่ โฟลเดอร์ข้อมูล\logs (server.log, postgres.log)
  พอร์ตชนโปรแกรมอื่น: แก้ "port" หรือ "pgPort" ใน config.json
